메가 메뉴를 기존 사이트에 통합하기

단계 1·2·3을 거쳐 색감·마스트헤드·블로그가 자리잡았다면, 이제 가장 큰 변화입니다. 기존 사이트의 인라인 메뉴([화두] [소식] [토론광장]…)를 메가 메뉴로 교체합니다. 가장 위험한 작업이라 가장 마지막에 합니다.

⚠ 위험도 높음 이 작업은 사이트의 핵심 내비게이션을 바꿉니다. 반드시 단계 1~3이 안정적으로 작동하는 것을 확인한 다음 진행하세요. 백업 필수.

사전점검 사항

  • 단계 1(마스트헤드·색감) 적용 완료
  • 단계 2(글 상세 페이지) 적용 완료
  • 단계 3(블로그 셋팅) 적용 완료
  • 현재 운영 중인 기능(관리자 모드, 동기화, AI 도우미) 모두 정상 작동
  • 모바일에서 단계 1~3 모두 깨지지 않음
  • index.html 새 백업 (index_backup_pre_megamenu.html)

변경 1기존 인라인 메뉴 제거

현재 마스트헤드 아래에 있는 인라인 텍스트 메뉴 영역을 통째로 제거합니다. 아래 패턴의 HTML 블록을 찾아 삭제하세요.

<!-- 이런 패턴의 블록을 통째로 제거 --> <nav class="..."> <a href="#hwadu">화두</a> <a href="#news">소식</a> <a href="#agora">토론광장</a> <a href="#bridge">인연의 다리</a> <a href="#builder">사이트 빌더</a> </nav>

대신 마스트헤드 우측에 메가 메뉴 트리거(차림표 버튼)를 추가합니다.

변경 4JavaScript 연결

기존 사이트의 <script> 블록 끝에 추가합니다. 기존 코드와 충돌하지 않도록 yl- 접두사 유지.

// 메가 메뉴 작동 — 기존 JS와 분리된 IIFE로 감싸기 (function() { const trigger = document.getElementById('ylMenuTrigger'); const mega = document.getElementById('ylMegaMenu'); const overlay = document.getElementById('ylMegaOverlay'); if (!trigger || !mega || !overlay) return; function open() { mega.classList.add('open'); overlay.classList.add('open'); trigger.classList.add('active'); document.body.classList.add('menu-open'); } function close() { mega.classList.remove('open'); overlay.classList.remove('open'); trigger.classList.remove('active'); document.body.classList.remove('menu-open'); } trigger.addEventListener('click', () => mega.classList.contains('open') ? close() : open() ); overlay.addEventListener('click', close); document.addEventListener('keydown', e => { if (e.key === 'Escape') close(); }); // 대분류 호버/클릭 → 2열·3열 동기화 document.querySelectorAll('.yl-cat-item').forEach(item => { item.addEventListener('mouseenter', () => switchPane(item.dataset.target)); item.addEventListener('click', () => switchPane(item.dataset.target)); }); function switchPane(target) { document.querySelectorAll('.yl-cat-item').forEach(c => c.classList.toggle('active', c.dataset.target === target) ); document.querySelectorAll('.yl-mega-col-2-pane').forEach(p => p.classList.toggle('active', p.dataset.pane === target) ); document.querySelectorAll('.yl-mega-col-3-pane').forEach(p => p.classList.toggle('active', p.dataset.pane === target) ); } })();

변경 5모바일 대응

화면 너비가 1024px 이하일 때는 3열을 1열로, 640px 이하에서는 카테고리만 보여주는 아코디언 형태로 자동 전환.

@media (max-width: 1024px) { .yl-mega-body { grid-template-columns: 1fr; } .yl-mega-col-1, .yl-mega-col-2 { border-right: none; border-bottom: 1px solid var(--yl-line); } } @media (max-width: 640px) { .yl-mega-body { display: block; } .yl-mega-col-2, .yl-mega-col-3 { display: none; } /* 모바일: 클릭 시 다음 단계로 슬라이드 (선택 사항) */ }

테스트통합 후 확인 사항

  • 차림표 버튼 동작: 클릭 시 메뉴 부드럽게 슬라이드 다운
  • 3열 동기화: 왼쪽 항목 호버 시 가운데·오른쪽이 즉시 바뀜
  • 닫기: X 버튼, 오버레이 클릭, ESC 키 모두 작동
  • 모바일: 폰 폭에서 1열 또는 아코디언으로 변환
  • 화두 링크: 메가 메뉴에서 화두 → 클릭 시 본문 화두 섹션으로 스크롤
  • 광장 링크: 메가 메뉴에서 아골라 → 본문 광장 섹션으로 스크롤
  • 관리자 모드: 메뉴와 관계없이 기존처럼 작동
  • 로그인 모달: 메뉴와 별개로 정상 작동
  • AI 도우미: 플로팅 버튼 가려지지 않는지
  • 키보드 접근성: Tab 키로 메뉴 탐색 가능한지

되돌리기와 점진적 적용

메가 메뉴가 너무 큰 변화여서 부담스럽다면, 더 작은 단위로 쪼갤 수 있습니다.

  1. 마이크로 단계 1: 차림표 버튼만 추가 (클릭 시 alert으로 "준비 중" 표시)
  2. 마이크로 단계 2: 단순한 사이드 드로어(v3 방식)로 시작
  3. 마이크로 단계 3: 사이드 드로어를 점차 3열 메가 메뉴로 확장
마지막 한 마디 이 4단계까지 끝나면 v4 시안의 모든 디자인이 실제 운영 사이트에 적용된 상태가 됩니다. 그 다음은 콘텐츠 — 매주 화두를 채우고, 광장을 살리고, 칼럼니스트를 모시는 일입니다. 디자인은 그 토대일 뿐이에요. 마을이 진짜로 자라는 것은 사람이 들어오기 시작하면서부터입니다.
