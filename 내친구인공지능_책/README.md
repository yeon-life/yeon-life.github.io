# 내 친구 인공지능

> 울산 연아카데미 **연소사** 의 AI 함께 쓰기 책

코드를 모르는 선생이 **Claude · ChatGPT · Gemini · Grok** 네 인공지능을 한 팀으로 묶어, 그 과정을 학생과 일반인이 따라올 수 있도록 쓴 이야기책입니다. 이 책은 **하나의 HTML 파일 안에 네 버전**이 들어 있어, 상단 탭으로 대상을 바꿔 읽을 수 있습니다.

## 버전 구성

- **일반인 버전** — 서장 + 13장 완성
- **중·고등부 버전** — 준비 중 (장별 요청 버튼으로 생성)
- **초등 5·6학년 버전** — 준비 중
- **초등 3·4학년 버전** — 준비 중

준비 중 버전은 각 장 아래의 "○○용으로 만들어 줘" 버튼을 누르면, 해당 장을 그 대상용으로 다시 써 달라는 요청 문구가 클립보드에 복사됩니다. 복사된 문구를 Cowork 대화창에 붙여 넣으면 Claude가 그 자리에 맞게 채워 줍니다.

## 함께 제공되는 것 (artifacts/)

- `연AI에이젼트기획팀.html` — 네 AI를 한 화면에 모은 라운드테이블 앱 *(복원 예정)*
- `통합협조문.html` — 네 AI에게 같은 형식으로 전달되는 공식 협업 문서 *(복원 예정)*
- `시작가이드.html` — API 키 발급 및 첫 사용 안내 *(복원 예정)*

## 수업 자료 (lessons/)

- `성인_1강_수업자료.html` — 90분 수업안 · 강사 대본 · 학생 활동지 *(복원 예정)*

## 사용법

1. `index.html`을 더블 클릭해 브라우저에서 열기
2. 상단 탭에서 읽고 싶은 버전 선택
3. 좌측 목차로 원하는 장으로 이동
4. 각 장 끝에서 학년별 버전 생성 요청 가능
