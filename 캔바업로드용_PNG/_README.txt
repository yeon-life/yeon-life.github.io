이 폴더의 PNG들은 우리가 만든 HTML 시안을 이미지로 변환한 것입니다.
캔바에서 작업하실 때 "업로드" 탭에 이 이미지들을 올려두시면,
캔버스 옆에 띄워두고 보면서 따라 만들 수 있습니다.

┌─────────────────────────────────────────────────────────┐
│  캔바에서 사용 방법                                     │
└─────────────────────────────────────────────────────────┘

1. 캔바 디자인 화면 열기
2. 좌측 메뉴에서 "업로드(Uploads)" 클릭
3. 이 폴더의 PNG들을 드래그해서 업로드
4. 작업하면서 옆에 띄워두고 참고

또는:
- 첫 작업할 때 PNG를 캔버스에 끌어다 놓고 "이것과 비슷하게 만들어줘"
  하면 Magic Design이 더 정확하게 따라 만들어줍니다.

┌─────────────────────────────────────────────────────────┐
│  알아두실 점                                            │
└─────────────────────────────────────────────────────────┘

· PNG는 정적 이미지라 호버·애니메이션이 안 보입니다.
  움직임을 확인하시려면 HTML 파일을 브라우저로 직접 여세요.

· 원본 HTML 파일을 옆에 함께 두는 것을 추천합니다.
  텍스트를 복사·붙여넣기로 가져올 때 편합니다.

· 일부 디테일(메가 메뉴 펼친 상태, 다크모드 등)은
  HTML에서만 확인 가능합니다.
