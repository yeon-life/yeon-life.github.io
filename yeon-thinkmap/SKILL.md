# yeon-thinkmap — 연라이프 광장 생각의 지도

> **"오직 진실과 진리를 찾는 곳 · y-life.kr 광장"**
>
> 마을 사람들의 생각이 어떻게 만나고 갈라지는지 한 장의 캔버스에 그리는 지도.

---

## ⚠️ 학습의 지도와 분리

이 스킬은 **생각의 지도 전용**이다. 학생 개인용 학습의 지도와 의도적으로 분리되어 있다.

| 항목 | 생각의 지도 (이 스킬) | 학습의 지도 (별도) |
|---|---|---|
| 대상 | 마을 전체 | 학생 1인 |
| 공개 | 공개, 모두가 봄 | 비공개, 본인만 |
| 목적 | 글의 연결망 시각화 | 자기 학습 분석 |
| 색 의미 | 글 종류(화두·아골라·아곤란·칼럼·연마을) | 학습 상태(완전학습·복습필요 등) |
| 적용처 | y-life.kr 광장 | 수풀·영풀·책풀·과풀·국풀 |
| 분석 차트 | 마을 활동 통계 | 본인 학습 추이 |

엔진 코드는 우연히 공유 가능하지만, **카테고리·라벨·UI 톤·인터랙션은 다르다.** 둘을 합치지 말 것.

---

## 1. 이 스킬을 부르는 경우

- 연라이프 광장 메인 페이지에서 "생각의 지도" 섹션
- 화두 페이지에서 "이 화두에 연결된 글들" 시각화
- 시민저널·칼럼이 서로 어떻게 인용·언급하는지 보여줄 때
- 광장 활동의 한 주·한 달 결산

---

## 2. 사용법 — 3줄

```html
<link rel="stylesheet" href="engine/thinkmap.css">
<div id="map" style="height: 100vh;"></div>
<script src="engine/thinkmap.js"></script>
<script>
  YeonThinkMap.mount('#map', {
    nodes: [
      { id: 'h-1', label: "'선택'이라는 말의 무게", cat: '화두', by: '임선생', size: 1.6 },
      { id: 'a-1', label: '왜요?가 많은 수업', cat: '아골라', by: '임선생', size: 1.2 },
    ],
    edges: [{ from: 'h-1', to: 'a-1' }],
    options: {
      title: '광장 생각의 지도',
      tagline: '오직 진실과 진리를 찾는 곳',
    }
  });
</script>
```

분석 대시보드도 같이 띄우려면 `analytics.js / analytics.css`를 추가 로드하고 `YeonAnalytics.mount(...)`.

## 3. 광장 5색 카테고리

```js
const PLAZA_CATEGORIES = {
  '화두':   { color: '#3aa0a8', label: '화두' },
  '아골라': { color: '#c4923e', label: '아골라' },
  '아곤란': { color: '#c05040', label: '아곤란' },
  '칼럼':   { color: '#6858c0', label: '칼럼' },
  '연마을': { color: '#4a9060', label: '연마을' },
};
```

이번 주 화두는 가장 큰 노드(`size: 1.6` 정도)로 중앙에 두고, 그 화두에 답하는 아골라·아곤란·칼럼·연마을 글들이 가지처럼 뻗어 나가는 구조가 기본.

## 4. 노드·엣지 데이터 형식 (광장용)

### 노드 (글 하나 = 노드 하나)

```js
{
  id: 'h-1',                           // 글 ID (서버 DB의 PK 또는 URL slug)
  label: "'선택'이라는 말의 무게",       // 글 제목
  cat: '화두',                          // PLAZA_CATEGORIES 의 키
  by: '임선생',                          // 작성자 닉네임
  time: '2시간 전',                      // 표시용 시간
  size: 1.6,                            // 0.5~2.0 (좋은물음·댓글·조회 종합)

  // 선택: 위치 (없으면 무작위)
  x: 0.5, y: 0.42,                      // 0~1 비율, 캔버스 크기에 자동 스케일

  // 선택: 상세
  body: '글 요약 또는 첫 문장',
  url: '/post/h-1',                     // 클릭 시 이동할 원글 URL
  lastSeen: '2026-05-15T10:00:00+09:00',
  depth: 24,                            // ◐ 좋은 물음 수 (광장 정서 지표)
  comments: 7,
  views: 86,
}
```

### 엣지 (글 사이 연결)

```js
{ from: 'h-1', to: 'a-1', type: 'connection' }

// 또는 짧게:
['h-1', 'a-1']
```

광장에서 자주 쓰는 엣지 타입:
- `'reference'` — 한 글이 다른 글을 인용·언급
- `'reply'` — 답글 관계
- `'same-theme'` — 같은 주제
- `'same-author'` — 같은 작성자
- `'connection'` — 일반 연결

## 5. 노드 크기 — "마을이 이 생각에 얼마나 응답했나"

크기는 **점수가 아니라 마을 응답의 시각화**다.

```js
size = sqrt(
  depth × 0.30           // ◐ 좋은 물음 카운트
+ comments × 0.25        // 댓글 수
+ views × 0.15           // 조회 (로그 스케일)
+ shares × 0.10          // 스크랩·공유
+ recency × 0.20         // 최근일수록 살짝 큼
) → 0.5 ~ 2.0 으로 정규화
```

화두는 마을 전체가 함께 읽는 글이라 보통 가장 큼. 학생 한 명의 짧은 질문은 작지만 응답이 많이 달리면 그만큼 커진다.

## 6. 분석 대시보드 (yeon-thinkmap-analytics)

같은 데이터를 다른 각도로 본다. 광장용으로 의미 있는 차트:

| 차트 | 광장에서 보여줄 것 |
|---|---|
| 카테고리 분포 도넛 | 화두·아골라·아곤란·칼럼·연마을 비중 |
| 활동 트리맵 | 카테고리·기간별 글의 부피 |
| 활발한 작성자 막대 | 이 주에 가장 많이 글을 쓴 사람들 |
| 좋은 물음 레이더 | 카테고리별 평균 ◐ 점수 |
| 일별 활동 캘린더 | 광장이 가장 뜨거웠던 날 |
| 댓글 폭발 막대 | 가장 많은 토론을 일으킨 글 |
| 새 글 라인 차트 | 한 달 동안 새 글이 어떻게 쌓였나 |
| 화두 → 가지 분석 | 이번 주 화두에 답한 글 분포 |

(현재 엔진의 `analytics.js`는 학습 지도용으로 만들어진 차트가 섞여 있다 — **광장용으로 다시 정리할 작업이 남아 있음.**)

## 7. 인터랙션

- **휠** — 확대·축소 (5% ~ 1600%)
- **드래그** — 보기 위치 이동
- **노드 클릭** — 우측 반투명 패널에 글 요약, 연결된 글 목록
- **연결 항목의 `›` 아이콘** — 전체 기록 패널 (더 넓고, 모든 메타데이터)
- **카테고리 필터** — 상단 필터 또는 좌하단 범례 클릭
- **검색** — 글 제목으로 빠르게 찾기
- **백업** — 우상단 ⤓: 광장 스냅샷을 JSON·MD·PNG로

## 8. 광장 정서 — 절대 어기지 말 것

- ❌ **점수·등수 매기지 말 것.** 노드 크기는 "마을 응답"이지 글의 우열이 아니다.
- ❌ **익명 글을 강제로 공개로 만들지 말 것.** 작성자가 익명을 선택했다면 그대로 둠.
- ❌ **삭제된 글을 흔적으로 남기지 말 것.** 노드와 엣지 모두 정리.
- ❌ **알고리즘이 글을 숨기지 말 것.** 모든 글이 지도에 나타나야 한다. 필터는 학생이 능동으로 거는 것.
- ✅ **이번 주 화두를 중앙에 두기.** 마을 전체의 중심.
- ✅ **새 글은 가장자리에서 부드럽게 등장.** 갑자기 튀어나오지 않음.
- ✅ **하단 모토 항상 노출** — "오직 진실과 진리를 찾는 곳 · y-life.kr 광장"

## 9. y-life.kr 통합 — 다음에 할 일

연라이프 홈페이지에 실제로 박을 때:

- [ ] `광장_생각지도.html` 을 y-life.kr 의 광장 페이지에 한 섹션으로 임베드 (iframe 또는 직접 통합)
- [ ] 메인 페이지(`YLHome.jsx`)의 미니 생각지도와 연동 — 클릭하면 풀 화면 생각의 지도로 이동
- [ ] 광장 글 DB와 연결 — 새 글이 올라오면 자동으로 노드 추가
- [ ] 작성자·댓글·좋은물음 카운트 → size 자동 계산 백엔드
- [ ] 분석 대시보드를 광장용으로 다시 정리 (학습 지도용 차트 제거, 광장용 차트 추가)
- [ ] 모바일 최적화 — 좁은 화면에서도 노드 라벨이 깨지지 않게

## 10. 파일 구조

```
yeon-thinkmap/
├─ SKILL.md                  # 이 문서
├─ template.html             # 최소 임베드 예제
├─ engine/
│  ├─ thinkmap.js            # 마인드맵 엔진 (1158줄, 학습/생각 공용)
│  ├─ thinkmap.css           # 스타일
│  ├─ analytics.js           # 분석 차트 (광장용 정리 필요)
│  └─ analytics.css
└─ examples/
   └─ 광장.json               # 광장 샘플 데이터 (20개 노드, 36개 연결)
```

엔진(`engine/`)은 학습의 지도와 공유한다 — 코드 자체는 도메인 중립적. 의미는 어떤 데이터를 넣느냐로 결정된다.
