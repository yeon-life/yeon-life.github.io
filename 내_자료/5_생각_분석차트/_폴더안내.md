# 5_생각_분석차트 — 그래프로 본 내 생각의 풍경

내 노드들이 모이면 단순한 목록이 아닙니다. **9가지 차트로 본인의 생각 패턴을 분석**합니다.
yeon-thinkmap-analytics 엔진이 `../3_내_생각지도/` + `../4_광장과_연결/` 데이터를 읽어
이 폴더에 차트별 결과를 떨어뜨립니다.

## 9가지 차트 — 본인 자료용

| 차트 | 어떤 질문에 답하나 |
|---|---|
| **카테고리 도넛** | 내 노드 중 개념·인용·질문·통찰·참고가 각각 얼마인가 |
| **출처 트리맵** | 어떤 책·논문·웹사이트에서 가장 많이 가져왔나 |
| **시간 라인 차트** | 한 달 동안 새 노드가 얼마나 쌓였나 (실제 데이터) |
| **광장 응답 레이더** | 광장 5색 카테고리 각각에 내가 얼마나 응답했나 |
| **연결 종류 막대** | same-source / agreement / contrast / extends / cites / inspired 비율 |
| **혼자 vs 광장 도넛** | 내 노드 중 광장과 연결된 것 vs 혼자인 것 |
| **관심 키워드 히트맵** | 시간 × 키워드 — 언제 어떤 주제에 빠져 있었나 |
| **사색 깊이 곡선** | 자료당 메모량 추이 — 깊이 읽는 게 늘고 있나 |
| **일별 활동 캘린더** | 매일 자료를 들여다본 흔적 |

모든 차트는 **본인의 실제 데이터**에서 나옵니다. 광장 차트와 달리 가짜 데이터·예시 배지가 붙지 않아요.

## 자동 생성되는 파일

```
5_생각_분석차트/
├─ 차트_데이터.json           ← 9개 차트가 쓸 통계 (계산 결과)
├─ 인사이트.md               ← AI가 쓴 한 문단 해설 ("이 주에 당신은…")
└─ 스냅샷/
   └─ YYYY-MM-DD_차트모음.html  ← 그날의 차트들이 인쇄 가능한 한 페이지로
```

## 차트 → 지도 양방향

분석 차트와 생각의 지도는 한 화면에서 같이 보입니다:

- 차트의 막대·도넛 조각을 **클릭** → 지도에서 해당 노드들만 강조
- 지도에서 노드를 **선택** → 그 노드가 차트 어디에 포함되는지 짚어줌

분석은 한 곳에서, 시각은 다른 곳에서 — 가 아니라 **둘이 같이 움직입니다.**

## 인사이트 메모 — AI의 짧은 해설

매주 일요일 차트가 갱신될 때 AI가 한 문단을 적어 줍니다:

> "이번 주 당신은 자유의지에 대한 자료를 5개 추가했고, 그중 3개가 광장의 '선택' 화두와 연결됐습니다.
>  광장의 다른 글들과 비교하면 당신의 관점은 신경과학에 가깝습니다.
>  contrast 관계가 2개 발견됐어요 — 광장에서 다른 시각을 보고 싶으시면 [이 글] 클릭."

이건 평가가 아니라 **거울**입니다. 본인이 어떤 풍경에 있는지 보여줄 뿐.

## 차트가 보여주지 않는 것

- 다른 사람과의 비교 (그건 광장 분석에서)
- "당신은 잘 하고 있어요" 같은 평가
- 점수·등수
- 광장에 자동 공유 (절대 안 함)
