# 내 자료 — 폴더 사용법

> **"여기에 떨어뜨리면 생각의 지도에 모입니다"**
>
> 본인이 평소에 쓰는 자료(PDF·문서·메모·웹스크랩)를 이 폴더에 넣으면
> AI가 분석해서 생각의 지도에 노드로 추가합니다.
> 광장(연라이프)의 다른 사람 생각과도 자동으로 연결됩니다.

---

## 폴더 흐름 — 자료가 지도가 되기까지

```
   0_받은_자료      →    1_추출된_텍스트  →    2_AI_분석결과
   (원본 보관)            (텍스트만 추출)         (개념·요약·키워드)
        ↓
   3_내_생각지도    ↔    4_광장과_연결    ←    (광장 데이터)
   (내 노드 모음)         (광장 노드와의 매핑)
        ↓
   5_비교_대조분석
   (내 생각 vs 광장 생각)
        ↓
   6_백업
   (정기 스냅샷)
```

각 단계가 무엇을 하는지 폴더별 안내(`_폴더안내.md`)에 적혀 있습니다.

---

## 어떻게 자료를 넣나요?

**텍스트 위주 자료 (무료 처리)**
- 메모: `내_자료/0_받은_자료/메모/` 에 `.md` 또는 `.txt` 파일
- 문서: `내_자료/0_받은_자료/문서/` 에 Word/HWP/Google Docs 다운로드본
- PDF: `내_자료/0_받은_자료/pdf/` 에 PDF 파일
- 웹 스크랩: `내_자료/0_받은_자료/웹스크랩/` 에 URL을 적은 `.txt` 또는 저장된 페이지

**무거운 처리 (유료, 1만원/월~)**
- 이미지 OCR: `내_자료/0_받은_자료/이미지_OCR대상/`
- 음성 전사: `내_자료/0_받은_자료/음성_전사대상/`

---

## 처리는 어떻게 일어나나요?

자료를 떨어뜨리면 (수동 트리거 or 자동 감지 둘 다 가능):

1. **추출 단계** — PDF/Doc 등에서 텍스트만 뽑아 `1_추출된_텍스트/` 에 `.txt` 로 저장
2. **AI 분석 단계** — Gemini Flash 또는 Claude Haiku로 분석해 `2_AI_분석결과/` 에:
   - `자료명_노드후보.json` — 추출된 개념 노드들
   - `자료명_요약.md` — 한 문단 요약
   - `자료명_키워드.json` — 키워드 목록
3. **승인 단계** — 본인이 노드 후보를 보고 "넣을 것"만 골라서 `3_내_생각지도/nodes.json` 에 합침
4. **연결 단계** — 새 노드와 광장 노드 사이 유사도 분석해 `4_광장과_연결/` 에 연결 매핑 저장
5. **비교 단계** — "내 생각 vs 광장에서 본 이 주제의 생각" 비교 문서를 `5_비교_대조분석/` 에 자동 작성

---

## 사생활 보호

- 이 폴더 전체는 **본인만 봅니다**. 광장에 공개되지 않습니다.
- 광장 노드가 본인 지도에 함께 나타나도, 본인 자료가 광장에 공개되는 것은 **아닙니다**.
- 클라우드 동기화 OFF가 기본 (원하면 켤 수 있음).
- 백업(`6_백업/`)도 본인 PC에 저장.

---

## 광장과 어떻게 연결되나요?

새로 만들어진 본인 노드 하나를 두고 시스템은 광장 노드를 둘러봅니다:

- **같은 주제** — 광장에 비슷한 화두·아골라 글이 있나?
- **반대 관점** — 광장에 본인 생각과 다른 관점의 글이 있나?
- **같은 인용** — 광장 글 어딘가에 본인이 읽은 책·논문이 인용됐나?
- **선후 관계** — 광장 글이 본인 자료의 기초가 되거나, 반대로 응용인가?

이 관계가 `4_광장과_연결/연결매핑.json` 에 쌓이고, 생각의 지도에서 본인 노드와 광장 노드 사이에 선이 그어집니다.

---

## 통합 지도에서는 어떻게 보이나요?

광장 5색에 더해 본인 노드는 **두 톤 색**으로 표시됩니다:

| 색 | 의미 |
|---|---|
| 🟦 진한 청록 | 광장의 화두 |
| 🟧 호박색  | 광장의 아골라 |
| 🟥 코랄    | 광장의 아곤란 |
| 🟪 보라   | 광장의 칼럼 |
| 🟩 초록   | 광장의 연마을 |
| 🟫 **금색 테두리** | **내 자료에서 온 노드** |
| 점선 연결 | 광장 ↔ 내 노드 사이 연관 |

본인 노드는 살짝 도드라져서 "이건 내 거"라는 게 한눈에 보입니다.
