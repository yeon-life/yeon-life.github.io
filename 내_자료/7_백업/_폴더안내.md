# 6_백업 — 본인 자료 전체 스냅샷

본인 지도와 자료가 통째로 보관되는 자리. **연라이프 정신 — "여기서 쓴 모든 것은 당신의 자산입니다."**

## 자동 백업 주기

- 매주 일요일 23:59 — 전주 스냅샷 자동 생성
- 큰 변화(노드 100개 이상 추가) 후 즉시 백업
- 분기별 (3·6·9·12월 말) 큰 백업

## 백업 파일 형식

```
6_백업/
├─ 2026-05-주차_스냅샷.zip
│  ├─ 3_내_생각지도/  (그 주의 모든 노드·엣지)
│  ├─ 4_광장과_연결/  (광장과의 연결 관계)
│  └─ _meta.json     (백업 시점, 노드 수)
├─ 2026-Q2_분기백업.zip
└─ ...
```

## 본인이 다른 도구로 옮기려면

zip 안의 `nodes.json + edges.json + categories.json`은
yeon-thinkmap 표준 형식이므로 어디든 호환됩니다.

연라이프 서비스가 사라져도 본인 백업만 있으면 다른 도구로 옮겨 계속 사용 가능.

## 백업 보관 위치

- 기본: 본인 PC의 이 폴더만
- 옵션 (본인이 명시적으로 켤 때만): 본인 Google Drive · Dropbox · iCloud 동기화
- **절대 연라이프 서버에 자동 업로드되지 않음**
