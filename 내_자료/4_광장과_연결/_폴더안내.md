# 4_광장과_연결 — 내 노드 ↔ 광장 노드 사이 다리

본인 노드와 광장 노드 사이의 관계가 쌓이는 자리. **이게 통합 지도의 핵심**입니다.

## 핵심 파일

```
4_광장과_연결/
├─ 연결매핑.json         ← 모든 연결 관계
├─ 광장노드_스냅샷.json   ← 최근 광장 노드 캐시 (오프라인 시각화용)
└─ 인사이트/
   └─ (광장 글이 내 자료와 닿은 순간들의 메모)
```

## 연결매핑.json 예시

```json
[
  {
    "from": "auto-libet-veto",
    "from_source": "내 자료",
    "to": "h-1",
    "to_source": "광장",
    "to_label": "'선택'이라는 말의 무게",
    "relation": "same-source",
    "strength": 0.92,
    "found_by": "ai-semantic-similarity",
    "found_at": "2026-05-15T17:50:00+09:00",
    "note": "Libet 실험을 본인 자료와 광장 화두 둘 다 다루고 있음"
  },
  {
    "from": "my-note-자유의지란",
    "from_source": "내 자료",
    "to": "h-2",
    "to_source": "광장",
    "to_label": "멈춤이라는 자유",
    "relation": "agreement",
    "strength": 0.78,
    "note": "내 노트와 연소사의 글이 같은 결론에 닿음"
  },
  {
    "from": "my-note-결정론은옳다",
    "from_source": "내 자료",
    "to": "a-1",
    "to_source": "광장",
    "to_label": "왜요?가 많은 수업",
    "relation": "contrast",
    "strength": 0.65,
    "note": "내 결정론적 관점과 임선생의 질문 중심 관점이 대비됨"
  }
]
```

## 관계 종류

| relation | 뜻 | 시각화 |
|---|---|---|
| `same-source` | 같은 자료를 다룸 | 굵은 점선 |
| `agreement`  | 같은 결론·관점 | 평범한 실선 |
| `contrast`   | 대비·반대 관점 | 빨강 점선 |
| `extends`    | 광장 글을 본인이 확장 | 화살표 실선 |
| `cites`      | 본인 자료가 광장 글을 인용 | 굵은 화살표 |
| `inspired`   | 광장 글에서 영감 받음 | 가는 곡선 |

## 자동 갱신 주기

- 본인이 새 자료를 추가할 때마다 광장 노드와 자동 비교
- 광장 노드가 새로 생겼을 때 본인 노드와의 연결 다시 점검 (주 1회)
- 새 연결 발견 시 알림: "당신의 [노트 제목]이 광장의 [글 제목]과 닿았습니다"
