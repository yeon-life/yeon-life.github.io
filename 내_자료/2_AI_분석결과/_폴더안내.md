# 2_AI_분석결과 — AI가 자료를 읽고 정리한 결과

`1_추출된_텍스트/` 의 .txt 한 편마다 AI 분석 결과가 세 종류로 떨어집니다.

## 각 자료당 만들어지는 파일

```
2_AI_분석결과/2026-05-12_Libet실험논문/
├─ 노드후보.json        ← 추출된 개념 노드들 (yeon-thinkmap 스키마)
├─ 요약.md              ← 한 문단 요약
├─ 키워드.json          ← 핵심 키워드 + 빈도
├─ 연관_광장글.json     ← 광장에서 비슷한 글 검색 결과
└─ 분석로그.md          ← 사용된 모델·토큰·비용
```
