# 0_받은_자료 — 원본 자료 보관소

자료가 처음 들어오는 자리. **원본은 절대 삭제되지 않습니다.**

## 하위 폴더 — 어디에 넣을지

| 폴더 | 넣는 것 | 처리 | 비용 |
|---|---|---|---|
| `pdf/` | PDF 파일 | 텍스트 추출 + AI 분석 | 무료 |
| `문서/` | Word(.docx), HWP, Google Docs 다운로드본 | 텍스트 추출 + AI 분석 | 무료 |
| `메모/` | 마크다운(.md), 텍스트(.txt) | 바로 AI 분석 | 무료 |
| `웹스크랩/` | URL을 적은 .txt, 또는 저장한 웹페이지 | 본문 추출 + AI 분석 | 무료 |
| `이미지_OCR대상/` | 사진·스캔본 (PNG, JPG) | OCR + 분석 | 유료 1만/월~ |
| `음성_전사대상/` | 녹음 (mp3, m4a, wav) | STT + 분석 | 유료 2만/월~ |

## 파일명 규칙 (권장)

자유로워도 되지만 다음 형식이면 시스템이 더 잘 정리합니다.

```
YYYY-MM-DD_제목_출처.확장자

예:
2026-05-15_명상록_5장요약_본인메모.md
2026-05-12_Libet실험논문_Neuroscience1983.pdf
2026-05-10_광장글답글_선택이라는말의무게.md
```

원본은 여기 그대로 남고, 추출된 텍스트는 `../1_추출된_텍스트/` 로 자동 이동.
