# 3_내_생각지도 — 내 노드와 연결 모음

본인이 승인한 노드와 연결이 모이는 자리. **이게 본인의 진짜 생각의 지도**입니다.

## 핵심 파일

```
3_내_생각지도/
├─ nodes.json            ← 내 노드 전체 (yeon-thinkmap 스키마)
├─ edges.json            ← 내 노드들 사이의 연결
├─ categories.json       ← 내가 정의한 카테고리 색상
└─ history/
   └─ YYYY-MM-DD_스냅샷.json   ← 매주 일요일 자동 백업
```

## yeon-thinkmap 형식과 호환

이 폴더의 `nodes.json + edges.json + categories.json`을 그대로 yeon-thinkmap 엔진이 읽어서 시각화합니다. 다른 도구로 옮겨도 그대로 호환.

## 내 카테고리 — 광장과 다르게 정의

광장은 `화두·아골라·아곤란·칼럼·연마을` 5색이지만, 본인 지도는 자유롭게 정의 가능:

```json
{
  "개념": { "color": "#3aa0a8", "label": "개념" },
  "인용": { "color": "#c4923e", "label": "인용·발췌" },
  "질문": { "color": "#c05040", "label": "내 질문" },
  "통찰": { "color": "#6858c0", "label": "내 통찰" },
  "참고": { "color": "#4a9060", "label": "참고할 것" }
}
```

기본값은 위 5색. 본인이 바꾸면 그대로 적용됨.
