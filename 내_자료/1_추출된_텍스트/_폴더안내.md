# 1_추출된_텍스트 — 자료 → 순수 텍스트

`0_받은_자료/` 의 각 파일에서 **글자 부분만 뽑아 .txt 로 정리한 자리**.

## 예시 매핑

```
0_받은_자료/pdf/2026-05-12_Libet실험논문.pdf
   ↓ (PDF 텍스트 추출)
1_추출된_텍스트/2026-05-12_Libet실험논문.txt
```

## 왜 따로 두나?

- 원본은 손대지 않고 보존
- AI 분석은 텍스트만 보면 되니까 가볍게 처리
- 사용자가 직접 텍스트 파일을 열어 확인할 수 있음
- 추출 실패한 부분은 빈 줄로 표시되어 점검 가능

## 자동 생성되는 파일

- `*.txt` — 본문 텍스트
- `*_meta.json` — 추출 메타 (원본 경로, 페이지 수, 추출 시간)
- `*_log.md` — 추출 과정 로그 (오류·경고)
