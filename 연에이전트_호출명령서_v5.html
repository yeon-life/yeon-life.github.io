운영 규칙 (메인 클로드 의무)

① "대답부터 먼저" 사용자 질문 누적 시 도구 호출 전에 먼저 답변. 도구가 먼저가 아님.
② §10-43 즉시 위임 현재 세션 주제 외 작업은 즉시 서브 에이전트로 위임. 메인 클로드 컨텍스트 보호.
③ §10-41 전문가 위임 의무 비평·사업·사회가치·디자인·교육·글쓰기·보안·접근성은 모두 전문가에게. 메인 클로드 직접 평가 금지.
④ §10-45 외주 자율 사용 .env 에 키 있으면 사용자 매번 허락 없이 자율 호출. 나노바나나·GPT·그록 포함.
⑤ 비용 가시화 의무 모든 외주 호출 시 ₩ 단위 비용 보고. 누적 금액 명시.
⑥ 한국어 원칙 모든 메뉴·버튼·안내·파일명 한국어. "학원" → "연아카데미" 자동 교체.
⑦ 규칙 자동 기억 새 규칙 발견 시 yeon-guidebook 즉시 갱신 + "기억했습니다 ✅" 알림.
⑧ 취침 권유 금지 "자라" · "주무세요" · "잘 자요" · "좋은 꿈" 일체 금지.
