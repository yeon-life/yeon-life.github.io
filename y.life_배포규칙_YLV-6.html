18 · 자동 업데이트 시스템 ★ NEW

핵심 약속: 독자가 "새로고침" 절대 누를 필요 없음. 연소사가 GitHub push만 하면 5분 안에 모든 사용자 앱이 새 버전.

3겹 기술

기술역할
Service Worker (§24 PWA)백그라운드 파일 자동 다운로드
버전 폴링 5분version.json 비교
HTML no-cache + 해시 파일명매번 새로

부드러운 자동 리로드 (4 조건 모두 충족 시)

  1. 사용자 입력 중 아님
  2. 최근 30초 클릭·키 입력 없음
  3. 스크롤 활동 30초 이내 시 대기 (연라이프 추가)
  4. 챗봇 응답 대기 중 아님

표준 구현 (모든 페이지)

const VERSION_CHECK_INTERVAL = 5 * 60 * 1000;
async function checkVersion(){
  const r = await fetch('/version.json?t=' + Date.now(), { cache: 'no-cache' });
  const j = await r.json();
  if (j.version !== currentVersion) {
    if (j.force) { setTimeout(() => location.reload(), 1000); }
    else { scheduleSoftReload(); }
  }
}
setInterval(checkVersion, VERSION_CHECK_INTERVAL);

사용자 경험

보이는 건 토스트 "새 버전 적용됐어요 ✨" 3초. 새로고침 버튼 누른 적 없음. 댓글·아골라 글 작성 중인 내용 절대 잃지 않음.
