연라이프의 비전과 철학

핵심 지향점

함께 만들어 갈 아름다운 세상 — 우리들의 대화 자체가 곧 그 공동 목표점.
인연으로 오고, 인연으로 간다

연라이프는 단순 홈페이지가 아니라 시대에 대한 문화적 응답입니다. 신뢰가 무너지고 의리와 도덕이 이익 앞에 흔들리는 지금, 사람들이 무엇을 먼저 생각해야 하나에 다시 관심을 갖게 하는 자리입니다.

세 대들보

  • 사필귀정(事必歸正) — 함께 묻고 따지면 결국 바른 곳으로
  • 말에는 마음씨가 그대로 담겨있다 — 모든 목소리에 존엄이 있음
  • 참된 것이 먼저 오는 자리 — 마음·과정·진실에 먼저 관심을 두는 구조

카피 원칙

"X가 아니라 Y" 구도는 사용하지 않습니다.

"말에는 마음씨가 그대로 담겨있다"는 정서를 토대로, 비교 프레임 없이 긍정적 언어로만 표현합니다.

❌ "틀린 공부가 아닌 바른 공부" → ✅ "마음씨가 담긴 공부"

사상적 토대

사람은 무의식적 최면 상태에서의 행동을 자신인 것으로 착각하며 산다. 의식이 할 수 있는 일은 거의 없다는 현대 심리과학의 결론이기도 하다. 그래서 종교·정치 같은 믿음 체계가 가장 위험하다. 여기에 사람의 욕심이 덧붙여지면 사이비가 된다.

Kahneman의 이중 처리, Libet 실험, 불교 무아(無我), 도교 무위(無爲)와 같은 지점에서 만납니다. 모든 기능은 의식의 틈을 여는 쪽으로 설계됩니다.

주요 버그 수정 기록

영풀 — 치명적 버그
모든 버튼 미작동 (스크립트 블록 조기 종료)
printShareCard()에 포함된 </script> 문자열이 HTML 파서를 혼동시켜, 스크립트 블록 4301번째 줄 이후 모든 JS가 실행되지 않았음. <scr'+'ipt>로 분할해 수정.
영풀 — 버그 2
scanForAbuse 정규식 문제
/</script>\n<script[\s>]/i 정규식에 </script>가 포함되어 같은 파서 문제 발생. /<script[\s>]/i로 수정.
수풀AI — QR 버그
QR 모달 함수들이 script 태그 밖에 위치
파일 하단의 openQRModal, closeQRModal, copyAppLink 함수들이 </script> 닫힌 후에 위치해 JS로 실행되지 않고 텍스트로 렌더링됨. <script> 태그로 감싸 수정.
공통 — git index 오류
error: bad signature 0x00000000 fatal: index file corrupt
NTFS 마운트와 git index 동기화 문제. rm -f .git/index && git read-tree HEAD로 해결.
