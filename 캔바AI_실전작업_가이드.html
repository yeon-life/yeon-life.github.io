캔바 AI로 직접 만드는 연라이프

준비된 의뢰서와 시안을 그대로 캔바 AI에 연결해 작업하는 실전 가이드입니다. Brand Kit 설정 → 페이지별 프롬프트 → 마무리 정리까지 한 번에 따라갈 수 있도록 정리했습니다. 처음 캔바를 다루셔도 충분합니다.

00

준비시작 전 알아둘 것

캔바 AI는 어떤 것인가

캔바에는 여러 AI 기능이 있는데, 우리에게 필요한 건 세 가지입니다.

  • Magic Design — 프롬프트(글)로 디자인을 만들어주는 기능
  • Magic Switch — 데스크탑 디자인을 모바일 사이즈로 자동 변환
  • Brand Kit — 우리만의 색·폰트·로고를 저장해서 모든 디자인에 일관 적용
⚠ 캔바 Pro가 필요합니다 Magic Design을 충분히 쓰려면 캔바 Pro 구독이 필요합니다 (월 11,900원, 1개월 무료 체험 있음). 무료 버전은 횟수 제한 있음.

예상 소요 시간

  • 준비 (Brand Kit 셋업): 1시간
  • 메인 홈페이지: 2~3시간
  • 광장 상세 페이지: 1~2시간
  • 블로그 템플릿 10종: 5~8시간 (한 번에 다 안 만들어도 됩니다)
  • 모바일 변환: 1~2시간
  • 마무리·내보내기: 1시간

전체 15~25시간. 며칠로 나눠서 하시면 부담 없어요.

1단계Brand Kit 셋업 (가장 먼저!)

Brand Kit에 우리 색·폰트·로고를 한 번 등록해두면, 이후 모든 디자인에 "Brand 적용" 버튼 하나로 자동으로 입혀집니다. 이게 안 되어 있으면 디자인마다 색을 일일이 입력해야 해요.

실행 순서
  1. 캔바 로그인 → 좌측 메뉴 "Brand" 클릭
  2. "+ Brand kit 추가" → 이름 "연라이프 y-life.kr"
  3. Brand Colors 섹션에서 아래 표의 12색을 하나씩 추가
  4. Brand Fonts에서 폰트 추가
  5. Brand Logos에 緣 텍스트 로고 (직접 만들거나 SVG로 업로드)

② 폰트 등록

2단계메인 홈페이지 만들기

실행 순서
  1. 캔바 홈에서 "맞춤형 크기" → 1440 × 4800px (긴 세로 페이지)
  2. 새 디자인 열린 후 왼쪽 사이드바에서 "Magic Design" 클릭

  4. 몇 개 시안이 나오면 가장 가까운 걸 고른 후 직접 다듬기

홈페이지 — Magic Design 프롬프트

A long-scrolling editorial homepage for "y-life.kr" — a Korean philosophical discussion platform. Aesthetic: "early morning trust" — quiet, contemplative, like a newspaper delivered at 6am. Color palette: warm ivory background (#F4F0E6), deep ink black text (#1A2326), deep teal accents (#2A5358), restrained amber highlights (#A87B3E). Typography: Noto Serif KR for headlines, Pretendard for body. Layout: top thin meta bar (date, my-blog pill) → tall masthead with large serif "緣 y-life.kr" brand → hero section with one giant philosophical quote ("This Week's Question") on the left and small editorial column on the right → BIG central "광장 (Plaza)" section with 3 columns (Agora, Agonran, Insights) — this is the heart of the page → smaller supporting sections below for columnists, news, citizen journalism. Warm, slow, sophisticated. Korean newspaper meets quiet literary journal. No bright colors. No stock photos of smiling people.
왜 영어 프롬프트인가 캔바 Magic Design은 영어 프롬프트에서 결과가 훨씬 좋습니다. 한국어로 넣으면 결과가 어색할 때가 많아요. 결과물의 텍스트만 한국어로 바꿔주시면 됩니다.

참고할 자료 — 캔바에 같이 띄우기

Magic Design은 텍스트만으로는 우리 시안의 디테일을 완벽히 못 살립니다. 다음 파일을 옆 모니터(또는 다른 탭)에 띄워두고 따라 그리세요.

  • 시안_v4_홈페이지.html — 가장 중요. 브라우저로 열어서 캔바 옆에 놓고 따라 만드세요.
  • 디자인시스템_새벽의신뢰.html — 색·폰트 위계 시각화

직접 다듬는 부분 — Magic이 못하는 것

  • 화두 인용문 (Noto Serif KR 46px 정도, 깊은 먹빛, italic 강조 일부)
  • "廣場 광장" 가운데 정렬 한자 로고 부분
  • 3열 광장 그리드의 비율 (1:1:1, 페이지의 거의 절반 차지)
  • "지금 깊어지는 중" 배지 (호박색, 작은 점 깜빡임 — 정지 이미지로는 점만)

4단계블로그 템플릿 10종

한 번에 10종을 다 만들지 마세요. 가장 많이 쓸 결 3~4개부터 만들고, 나머지는 천천히. 캔바에서는 "이 디자인 복사 → 변형" 방식이 효율적입니다.

블로그 — 공통 베이스 프롬프트

Personal blog page on Korean philosophical community platform. Default page width 1080px. Section order: cover image strip → profile (circular photo, name, handle, italic bio, stats row) → horizontal tab nav (소개·글·광장·가게) → main content. Same color palette: warm ivory background, deep ink text, teal accents, amber for time markers only. Tone: calm, literary, like a quiet newspaper columnist's page. No commercial vibes. Default sections: intro, recent posts, plaza activity (auto-pulled), optional shop card.

각 결마다 추가할 한 줄

위 공통 베이스를 만든 후, 각 결마다 아래 한 줄을 추가하거나 변형:

No.01 정직 (Editorial Quiet) — 기본형

Style: classic newspaper editorial. Clean grid, dashed dividers, serif headlines.

No.02 여백 (Open White)

Style: ultra-minimal, almost pure white background, centered alignment, very narrow content column (max 680px), tiny meta text, lots of breathing room.

No.03 노트 (Notebook)

Style: ruled notebook paper background (subtle horizontal lines every 32px in cream), red vertical margin line on the left, handwritten font for headlines (Nanum Pen Script), warm cream paper tone (#F7F1DE).

No.04 카드 (Stacked Cards)

Style: photo-driven 3-column card grid for posts, each card has a colored gradient placeholder image, category tag, title, snippet, footer meta. Pinterest-like browsing.

No.05 장서 (Bookshelf)

Style: dark left sidebar (280px wide, deep ink background, cream text) showing category list like book spines, right side cream background with article list showing book numbers (012, 011, 010...) like library catalog.

No.06 편지 (Letter)

Style: envelope/letter aesthetic, postage stamp graphic in top right (red border, 林 character inside), typewriter monospace font for body, handwritten signature, dashed border dividers. Warm aged paper (#FAF6E9).

No.07 잡지 (Magazine)

Style: magazine masthead with "Issue 12" label, giant bold serif headline (60-70px), 2-column body layout with drop cap, sidebar list of "in this issue" headlines, magazine indicia footer.

No.08 풍경 (Horizontal Scroll)

Style: horizontal scrolling panels in main area (5 panels, 340px wide each, 480px tall), one panel "active" in deep ink with cream text, others in cream surface. Series-based content.

No.09 묵화 (Ink Brush)

Style: large hanja (Chinese characters) as visual anchor, vertical thin red seal stamp graphic, ink-wash gradients in background, classical East Asian book aesthetic. Cream-yellow paper (#F7F3E7).

No.10 풀잎 (Botanical)

Style: greenish ivory background (#EEF2E8), small floating leaf characters as decoration, rounded sans-serif font (Gowun Dodum), green accents instead of teal, friendly cards with rounded corners (16px). Student/nature theme.

5단계모바일 변환

데스크탑 디자인이 완성된 후 모바일로 옮기는 가장 빠른 길은 Magic Switch입니다.

실행 순서
  1. 완성된 메인 홈페이지 디자인 열기
  2. 상단 우측 "Resize & Magic Switch" 클릭 (Pro 전용)
  3. "Mobile" 또는 "Instagram Story" 사이즈 선택 (375 × 8000px 정도)
  4. 자동 변환 후 직접 다듬기 — 3열 → 1열로 합쳐졌는지, 광장 섹션이 가장 잘 보이는지

모바일에서 직접 다듬을 부분

  • 3열 그리드 → 1열로 (자동 합쳐지긴 함)
  • 마스트헤드의 슬로건 줄(tagline) 숨김 — 너무 좁아짐
  • 차림표 버튼은 그대로 우측
  • 광장 헤더 "廣場 광장" 크기 약간 줄임 (44px → 28px)
  • 본문 글자 17px 그대로 유지

참조 파일: 시안_v4_모바일.html — 폰 프레임 4개로 정답 보여드림

7단계마무리 — 내보내기·공유

일관성 체크

  • 모든 페이지가 같은 색을 쓰고 있나? (Brand Kit 적용 일관)
  • 모든 페이지의 폰트가 일치하나? (Noto Serif KR + Pretendard)
  • 화두 인용은 항상 italic + 딥 틸?
  • 호박색은 정말 강조 자리에만 쓰였나?
  • "광장이 페이지 중심" 원칙이 지켜졌나?
  • 모바일 버전에서도 깨지지 않나?

내보내기

  1. PNG (2x) — 각 페이지 별도 (개발자가 참고용으로 씀)
  2. PDF 합본 — 모든 페이지를 한 파일로 (포트폴리오용)
  3. 공유 링크 — 캔바에서 "공유 → 보기 전용 링크" 생성

트러블슈팅자주 막힐 부분

Magic Design 결과가 영 다르게 나와요

프롬프트가 너무 길거나 짧을 때 흔히 일어납니다. 우리 프롬프트는 의도적으로 길게 썼는데, 그래도 안 되면:

  • 프롬프트를 두 줄 정도로 핵심만 압축해서 다시 시도
  • "start with a similar template" 옵션을 켜고 비슷한 캔바 템플릿에서 시작
  • "Editorial newspaper website" 같은 키워드를 더 강조

한국어가 폰트에 따라 깨져요

  • Noto Serif KR이 없으면 → Noto Sans KR로 대체
  • Pretendard가 없으면 → Noto Sans KR Light 또는 맑은 고딕
  • 모든 텍스트 박스를 선택 후 일괄로 폰트 적용

색이 의도한 것보다 어두워 보여요

캔바 미리보기는 모니터에 따라 다르게 보입니다. 실제 색은 HEX 코드 기준입니다. 의심스러우면 Brand Kit의 정확한 HEX 코드를 다시 확인하세요.

한자(緣·廣場 등)가 안 보여요

  • Noto Serif KR이나 맑은 고딕은 기본 한자 지원
  • 안 보이면 텍스트 박스 폰트를 "Noto Sans CJK"로 바꿔보세요

Magic Switch 결과가 망가져요

긴 페이지일수록 자동 변환이 어색해집니다. 다음 방법을 시도하세요:

  • 섹션 단위로 나눠서 변환 (히어로만 따로, 광장만 따로)
  • 자동 변환 후 30% 정도는 수동 정리 각오
  • 모바일은 시안_v4_모바일.html을 보고 처음부터 새로 만드는 게 빠를 수도 있음
09

마지막잊지 말아야 할 다섯 가지

  1. 광장이 페이지의 중심 — 칼럼·세상·어디로·미래는 모두 광장을 받치는 보조 섹션
  2. 색은 절제 — 호박색(#A87B3E)은 "이 주의 ___" 같은 시간 표식에만
  3. "X가 아니라 Y" 비교 프레임 금지 — 우리 카피는 비교가 아닌 마음씨로
  4. "좋은 물음"이 곧 우리 어휘 — 좋아요 X, 좋은 물음 ◐
  5. 새벽 6시의 호흡 — 빠른 SNS의 반대편이 우리의 자리
막히면 가이드의 어디로 돌아갈까 어떤 시안의 어디를 어떻게 만드는지 모를 때는 시안_v4_홈페이지.html과 디자인시스템_새벽의신뢰.html을 다시 열어보세요. 이 둘이 모든 답을 가지고 있습니다.
혹시 캔바 작업이 너무 어렵다면 부담 없이 말씀해 주세요. 크몽에서 디자이너를 고용하는 길로 전환할 수 있고, 그때는 의뢰서 ZIP만 보내시면 됩니다. 캔바 직접 작업이 정답은 아니에요 — 본인의 시간과 결과물 사이의 균형이 답입니다.
