# 그림 슬롯 지시서 — 「ㄱㄴㄷ 친구들이 깨어났어요」

> Gemini / 안티그래비티용. 이 표대로 **장면마다 서로 다른 그림**을 생성해 `images/`에 파일명 그대로 저장하면 HTML이 페이지별로 표시한다.
> 모든 페이지가 똑같으면 안 됨. 각 장면 글 내용을 그대로 그릴 것.

---

## 🎨 v1.5 제작 방식 확정 (2026-06-03, 연소사)

- **표지(cover.png)는 힉스필드로 이미 확정 생성됨** → `images/cover.png` 가 **이 책 전체의 스타일·캐릭터 기준**이다. 내부 16장은 이 표지와 같은 세계의 그림으로 보여야 한다.
- **내부 16장(p01~p16)은 Antigravity가 생성** — 아래 표 + 공통 화풍을 따르되, **반드시 `images/cover.png`를 레퍼런스(참조 이미지)로 첨부**해 캐릭터 생김새·색감·붓질을 일치시킬 것. (z_image는 페이지 간 일관성이 약해 표지만 맡고 내부는 Antigravity가 레퍼런스 기반으로 맡는다.)
- **캐릭터 = 절충안**: 표지처럼 **둥글고 통통한 파스텔 캐릭터(큰 눈·발그레한 볼·작은 팔다리)** 를 기본으로 하되, 각 자음은 **몸 실루엣이나 작은 특징으로 자음을 은근히 암시**한다(ㄱ=한쪽이 갈고리처럼 굽음, ㄴ=낮게 ㄴ자로 앉음, ㄷ=한쪽 열린 브래킷 느낌, ㅇ=완전한 동그라미, ㄹ=구불구불 등). **읽히는 글자·텍스트는 절대 넣지 않는다**(실루엣·자세·소품으로만 암시).
- 표지와 같은 **부드러운 파스텔 수채(오므리 화풍)**, 따뜻하고 둥근 톤 유지.
- 저장: `images/p01.png` ~ `images/p16.png` (파일명 그대로). 완료 후 Claude가 받아 책에 반영·확인.

## 공통 화풍 (모든 슬롯 적용)

- 「구름 로봇 오므리」 분위기: **부드러운 파스텔 수채(연한 살구·하늘·민트·라벤더), 따뜻하고 밝은 톤, 둥글둥글한 형태, 굵은 윤곽선 없이 번지는 가장자리.**
- **글자 의인화**: 한글 자음(ㄱ ㄴ ㄷ…)을 **글자 모양 그대로의 몸 + 동그란 눈 + 작고 통통한 팔다리**가 있는 귀여운 캐릭터로 표현. 각 자음의 모양 특징을 살릴 것(ㄱ=구부러진 등, ㄴ=눕는 형태, ㄷ=한쪽 열린 문, ㅇ=동그란 배, ㄹ=구불구불한 몸통 등).
- **그림 안에 글자·텍스트·숫자 삽입 금지** (언어 무관 전 세계 재사용 가능하게).
- 무서운 표정·어두운 톤·으스스한 분위기 금지. 캐릭터는 항상 귀엽고 따뜻하게.
- 인물·캐릭터는 화면 가운데~위 절반에 배치. 아래 공간은 본문 글 자리로 비워둘 것.
- 비율: 장면 이미지 1024×768(4:3), 표지 1024×1365(3:4).
