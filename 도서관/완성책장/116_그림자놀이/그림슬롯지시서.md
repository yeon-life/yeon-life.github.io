# 그림 슬롯 지시서 — 「그림자 놀이」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = **도담이**(초1·2 또래의 둥근 얼굴 아이). 발그레한 볼, 동그란 눈, 환한 미소. 모든 장면에서 같은 옷·머리 모양으로 일관.
- **과학 현상(그림자)을 직관적으로** 표현: 빛의 방향, 그림자의 위치(빛 반대쪽), 길이·크기 변화가 한눈에 보이게.
- 색감: 크림빛 배경 + 파스텔 살구·민트·연노랑·연하늘. 그림자는 회보라·연남색의 부드러운 반투명 톤(새까만 검정 대신 포근하게).
- **그림 안에 글자·숫자 활자 삽입 금지.**
- 페이지마다 구도·배경·빛의 방향이 분명히 다르게(같은 배경 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
