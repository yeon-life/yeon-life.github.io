# 그림 슬롯 지시서 — 「하루가 빙글빙글」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 하루의 빛 변화를 색으로 또렷이 보여 줌: 아침 햇살(맑은 노랑·복숭아빛) → 한낮(밝은 하양·하늘색) → 오후(따뜻한 살구빛) → 노을(주황·분홍·보라) → 밤(짙은 남색·별빛). 페이지마다 빛과 색이 분명히 다르게.
- 시계·해·달은 동그란 얼굴을 가진 다정한 캐릭터로 의인화 가능(동그란 눈, 작은 미소, 발그레한 볼).
- **그림 안에 글자·숫자 활자 삽입 금지.** (시각은 바늘의 위치로만 표현, 활자 숫자 X)
- 페이지마다 구도·등장 요소·시간대 배경이 분명히 다르게(같은 배경 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
