# 그림 슬롯 지시서 — 「별이 뜬 밤」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = 잠옷을 좋아하는 작은 아이 한 명(둥근 얼굴, 발그레한 볼, 큰 눈, 짧은 머리). 페이지마다 같은 아이로 일관되게.
- **하루의 빛 변화가 핵심**: 한낮 햇살 → 붉은 노을 → 보랏빛 저녁 → 짙은 남색 별밤 → 다시 밝은 아침. 페이지가 넘어갈수록 하늘색이 분명히 달라지게.
- 별·달·노을·시계 등 사물을 부드럽게 의인화해도 좋음(작은 눈·미소). 단 과하지 않게.
- **그림 안에 글자·숫자 활자 삽입 금지.** (시계 숫자도 활자 대신 점·눈금 느낌으로만)
- 페이지마다 구도·시점·배경·하늘색이 분명히 다르게(같은 배경 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
