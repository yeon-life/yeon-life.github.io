# 그림 슬롯 지시서 — 「저녁노을이 물들어」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = 볼이 발그레한 6~8세 아이 한 명(짧은 머리, 동그란 눈, 작은 체구). 페이지마다 같은 아이로 일관되게.
- **하루의 빛 변화를 페이지마다 분명히 다르게**: 한낮의 밝은 햇살 → 노을의 주황·분홍 → 어스름 → 별밤의 짙은 남색. 시간이 흐를수록 화면이 점점 어두워지고 따뜻한 등불빛이 강해지게.
- 색감 기본: 크림빛·아이보리 바탕에 파스텔 살구·주황·분홍·연보라·남색을 시간대에 맞게.
- **그림 안에 글자·숫자 활자 삽입 금지.** (시계 슬롯의 숫자도 활자 대신 점·눈금으로만 암시)
- 페이지마다 구도·시점·배경 요소가 분명히 다르게. 같은 배경 반복 금지.
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
