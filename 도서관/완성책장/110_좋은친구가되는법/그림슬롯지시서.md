# 그림 슬롯 지시서 — 110 좋은 친구가 되는 법

## 공통 화풍 (모든 슬롯 동일 적용)
- 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화 톤
- 형태: 둥근 선, 둥글둥글한 형태, 따뜻하고 포근한 분위기
- 표정: 작은 눈·발그레한 볼·살짝 미소로 감정을 또렷하게. 과하지 않게, 귀엽게
- 캐릭터 일관성:
  - 노을이(아기 여우, 주황빛 털, 흰 가슴, 복슬한 꼬리, 하늘색 목도리)
  - 도토(다람쥐, 갈색 털, 줄무늬 꼬리, 늘 도토리 하나를 들고 있음)
  - 가시(고슴도치, 연회색 가시, 분홍 작은 코, 수줍은 표정)
- 금지: 그림 안에 글자·숫자 텍스트 삽입 금지 (말풍선·간판 글자 모두 금지)
- 배경: 연한 단색 또는 부드러운 그라데이션, 숲·언덕·풀밭 모티프, 여백 충분히
- 구도: 페이지마다 구도·표정·장면을 서로 다르게. 같은 배경 반복 금지
