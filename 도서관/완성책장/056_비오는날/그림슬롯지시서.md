# 그림 슬롯 지시서 — 비 오는 날 (056)

공통 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻한 빛, 포근한 질감. 구름·빗방울·화분·개구리·지렁이·달팽이를 의인화(작은 눈·볼·미소). 그림 안에 글자·숫자 표기 절대 금지. 페이지마다 장면·색감·구도를 서로 다르게(같은 배경 반복 금지). 색칠 손놀이용 라인 시트는 연필 스케치 톤(가는 회색 외곽선, 채색 없음).
