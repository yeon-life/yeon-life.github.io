# 그림 슬롯 지시서 — 084 신발 끈 묶기

## 공통 화풍 (모든 슬롯 동일 적용)
- 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화 톤
- 형태: 둥근 선, 둥글둥글한 형태, 따뜻하고 포근한 분위기
- 의인화: 신발과 신발 끈을 살짝 의인화(작은 눈·발그레한 볼·옅은 미소). 과하지 않게, 귀엽게. 토끼 귀 모양 매듭은 진짜 토끼 귀처럼 쫑긋하게 표현
- 캐릭터 일관성: 토리(초등 1학년 아이, 단발머리, 노란 티셔츠와 멜빵 반바지, 파란 운동화), 엄마(긴 머리 묶음, 연두색 앞치마, 품에 아기 동생을 안음), 동생(작은 아기, 분홍 배냇저고리)
- 동작 강조: 신발 끈을 묶는 손동작을 매 장면 또렷하고 크게. 끈의 모양(축 늘어짐 → 엑스 → 토끼 귀 둘 → 매듭)이 페이지마다 분명히 달라지도록
- 금지: 그림 안에 글자·숫자 텍스트 삽입 금지 (운동화 무늬는 점·별 정도만)
- 배경: 연한 단색 또는 부드러운 그라데이션, 여백 충분히
- 구도: 페이지마다 구도·표정·시점(전신/클로즈업/손 위주)을 서로 다르게
