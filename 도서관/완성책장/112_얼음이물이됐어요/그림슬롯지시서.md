# 그림 슬롯 지시서 — 얼음이 물이 됐어요 (112)

공통 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻한 빛, 포근한 질감. 얼음·물방울·김 등 사물을 작은 눈·볼·미소로 의인화. 상태 변화(얼음→물→김)가 한눈에 보이도록 직관적으로 그린다. 그림 안에 글자·숫자·온도 표기 절대 금지. 페이지마다 장면·색감·구도를 서로 다르게(같은 배경 반복 금지). 색칠 손놀이용 라인 시트는 연필 스케치 톤(가는 회색 외곽선, 채색 없음).

주인공: 민지(짧은 단발, 호기심 가득한 표정의 초등 1~2학년 여자아이). 모든 장면에서 같은 얼굴·옷차림 유지.
