# 받침 없는 글자 나라 — 그림 슬롯 지시서

- 전체 스타일: 부드러운 파스텔 수채화. 동글동글하고 따뜻한 톤. 가는 색연필 윤곽.
- 캐릭터 컨셉: 글자들은 발 없이 동동 떠다니는 동그란 젤리 캐릭터. 작은 점눈과 발그레한 볼. 받침이 없어 통통 가볍게 떠 있는 느낌. (글자 자모를 직접 그려 넣지 말 것 — 글자 형상은 추상적 둥근 캐릭터로만 표현)
- 색감: 연노랑·연분홍·하늘색·연두 중심의 밝은 파스텔.
- 공통 금지: 그림 안에 어떤 문자·숫자·글자도 삽입 금지. 무서운 표정·어두운 색·날카로운 형태 금지.
- 본문 크기: 1024 x 768 (가로). 표지: 768 x 1024 (세로).
