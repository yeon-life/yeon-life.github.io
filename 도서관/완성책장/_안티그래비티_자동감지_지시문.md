## 0. 상시 감시 루프
1. **`C:\C-Antigravity\연라이프-도서관\완성책장\` 를 주기적으로 스캔**(파일 감시 가능하면 watch, 아니면 1~3분 폴링).
2. 각 책 폴더에서 **마커로 상태 판단**:
   - `_제작완료.md` 있음 **AND** `_배포완료.md` 없음 → **처리 대상**.
   - 처리 시작 시 `_안티작업중.md` 생성(중복 방지), 끝나면 지우고 `_배포완료.md`(공개 URL 기록) 생성.
3. 처리 대상이 여러 개면 번호 순으로 하나씩.

## ⚠️ 0-A. 가장 중요 — 우리 엔진(완성본.html) 그대로 쓸 것
- 각 책 폴더의 `완성본.html` 은 **연 동화책 엔진**이다(스크롤 읽기 + 스페이스/엔터 한 장씩 + 🌐 한↔영 에디션 전환 + 모든 낱말 클릭→한/영 뜻+소리 + 챗봇 + 글자크게 + 학년별 활동지 + 미래사고).
- **이 HTML을 자체 빌드로 새로 만들거나 덮어쓰지 말 것.** (예전에 88KB 자체 빌드로 덮어써서 위 기능이 사라지고 페이지 그림이 다 똑같아진 사고가 있었음.)
- 네가 할 일은 **그림을 그려 `images/`에 넣고 + PWA/manifest/sw 추가 + 배포**뿐. 엔진 HTML·data.js 는 건드리지 말 것.

## 1. 한 권당 마무리 작업 (각 폴더)
폴더 구성: `data.js` + `완성본.html`(엔진) + `그림슬롯지시서.md` + `검수보고.md`.
**오므리 최종 표준을 동일 적용** — 기준 문서:
`C:\C-Antigravity\연라이프-도서관\01_초등1학년_초급\002_구름로봇오므리…\오므리_작업명령서_v2.md`
적용 항목:
- **§8 이미지 ⭐(중요)**: `그림슬롯지시서.md` 대로 **장면마다 내용에 딱 맞는 서로 다른 그림**을 생성 → `images/`에 파일명 그대로(없으면 SVG 폴백). **장면이 비슷비슷하면 안 됨 — 각 페이지 글·상황을 그대로 그릴 것.**
  - **화풍 통일**: 「구름 로봇 오므리」 느낌 — **부드러운 파스텔 수채, 따뜻한 하늘·구름 배경, 둥글고 친근한 선.** (오므리 책 참고)
  - **의인화**: 글자·사물·동물을 **표정과 성격이 있는 캐릭터로 의인화**해서 그릴 것. (예: 한글 깨우기 = ㄱㄴㄷ 글자들이 눈·표정 가진 친구 캐릭터, 받침=콩 캐릭터 등) 아이가 정 붙이게.
  - 글자 삽입 금지(언어 무관 재사용). 색칠 손놀이=연필 스케치 톤, 모든 손놀이는 책 내용과 관련(범용 금지).
- **§2 PWA**: start_url="/"·scope="/", 서비스워커 전 자산 precache + 캐시우선·네트워크폴백, **캐시버전+skipWaiting()+clients.claim()**(설치본도 새 버전 즉시 반영, ERR_FAILED 금지).
- **§2-B 떨림 제거**: 상단바 `backdrop-filter:blur` 제거(반투명 단색), 구름 애니 정지/`prefers-reduced-motion` 존중, 플립 3D는 펼친 leaf만 GPU힌트.
- **§1 진입**: 바로 책장 → 책 클릭해 열기. **§3 우측상단**: 🌐한/영·⚙️옵션·📚내서재·🔗공유(QR+원클릭복사).
- 자족형·한국어·콘솔 오류 0·모바일·키 프론트 금지(서버 프록시).

## 2. 배포
- Cloudflare Pages 배포 → 공개 URL. **실제 설치·오프라인 실행 테스트**(ERR_FAILED·떨림 재현 없는지).

## 3. 카톡 전송 + 마커
- 공개 URL을 **연소사(이진우)에게 카카오톡 전송**(불가 시 URL·QR 크게 안내).
- 폴더에 `_배포완료.md` 작성(공개 URL·점검 결과 기록), `_안티작업중.md` 삭제.
- `완성책장\_배포현황.md` 에 권별 URL 누적 기록.

## 4. 멈춤 조건

- 오류 시 그 폴더에 `_오류.md` 남기고 다음 권으로(전체 멈추지 말 것).
