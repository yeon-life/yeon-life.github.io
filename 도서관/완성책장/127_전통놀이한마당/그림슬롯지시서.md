# 그림 슬롯 지시서 — 「전통 놀이 한마당」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 정겨운 한국 명절 분위기.
- 등장인물: 한복 입은 두 어린이 — 소율(여, 분홍·연두 색동저고리에 다홍 치마, 양 갈래 댕기), 도진(남, 연하늘 저고리에 남색 바지, 까치두루마기). 둥근 눈, 발그레한 볼, 환한 미소.
- 어른: 한복 입은 할아버지(흰 두루마기·갓 또는 흰 머리), 할머니(옥색 저고리·쪽진 머리). 인자한 표정.
- 배경: 한옥 기와집과 나무 마루, 흙 마당, 장독대, 문창살. 전통 소품은 사실에 맞게(윷가락 4개·둥근 윷판·천으로 싼 제기).
- 색감: 크림빛·미색 배경 + 다홍·옥색·연두·남색·살구 등 한복 빛깔의 파스텔.
- **그림 안에 글자·활자 삽입 금지.**
- 페이지마다 구도·등장 인물 수·배경 요소가 분명히 다르게.
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
