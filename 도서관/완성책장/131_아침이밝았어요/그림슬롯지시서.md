# 그림 슬롯 지시서 — 「아침이 밝았어요」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = 잠옷·평상복 차림의 작고 동그란 아이 한 명. 동그란 눈, 발그레한 볼, 환한 미소.
- **하루의 빛 변화**가 핵심: 새벽 남보라 → 동틀 무렵 분홍빛 → 떠오르는 붉은 해 → 환한 노란 아침 햇살로 페이지마다 빛과 색 온도를 분명히 다르게.
- **그림 안에 글자·숫자 활자 삽입 금지.** (시계 숫자도 점·눈금으로만 표현, 활자체 텍스트 X)
- 페이지마다 구도·시점·배경 요소가 분명히 다르게(같은 방·같은 각도 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
