# 그림 슬롯 지시서 — 「커서 뭐가 될까?」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = 다온이(짧은 단발 머리, 동그란 눈, 발그레한 볼, 노란 멜빵바지 또는 부드러운 살구빛 옷). 모든 장면에서 같은 모습 유지.
- 색감: 크림빛 배경 + 파스텔 살구·연노랑·연두·연보라.
- **그림 안에 글자·활자·말풍선 텍스트 삽입 금지.** (감정은 표정과 몸짓으로만 표현)
- 페이지마다 구도·배경·등장인물 수·시간대가 분명히 다르게(같은 배경 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
