# 그림 슬롯 지시서 — 「거미줄이 반짝반짝」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 거미 '동글이'는 **의인화**: 동글동글한 몸에 다리 여덟 개(과학적으로 정확하게 8개), 동그란 눈, 발그레한 볼, 다정한 미소. 무섭지 않고 귀여운 이웃처럼.
- 계절감: 이른 여름~초가을 아침의 풀숲. 이슬·안개·아침 햇살의 맑은 공기.
- 색감: 크림빛·연한 풀빛 배경 + 파스텔 민트·살구·연보라·연하늘. 이슬 물방울은 맑은 흰빛 반짝임.
- **그림 안에 글자·숫자 활자 삽입 금지.**
- 페이지마다 구도·시점(원경/근접/클로즈업)·등장 요소가 분명히 다르게. 같은 배경 반복 금지.
- 거미줄은 **둥근 동심원형 그물**로 정확히(가운데서 뻗은 살 + 빙 도는 나선 줄).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
