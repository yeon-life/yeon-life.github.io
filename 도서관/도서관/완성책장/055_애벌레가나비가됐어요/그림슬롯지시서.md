# 그림 슬롯 지시서 — 애벌레가 나비가 됐어요 (055)

공통 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻한 빛, 포근한 질감. 애벌레·나비·배추 잎 등 자연물을 살짝 의인화(작은 눈·볼·미소). 그림 안에 글자·숫자 표기 절대 금지. 페이지마다 장면·색감·구도·계절감을 서로 다르게(봄~초여름의 변화를 은은히 담기). 색칠 손놀이용 라인 시트는 연필 스케치 톤(가는 회색 외곽선, 채색 없음).
