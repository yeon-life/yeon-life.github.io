# 그림 슬롯 지시서 — 085 아침에 일어나요

## 공통 화풍
- 「구름 로봇 오므리」식 부드러운 파스텔 수채 + 둥근 선. 따뜻하고 포근한 분위기.
- 주인공 **토토**(작은 곰돌이 아이, 노란 잠옷). 동작이 또렷하게 보이도록.
- 사물 의인화 가능(이불·시계·해님이 다정한 표정).
- **그림 안에 글자 삽입 금지.**
- 색칠 손놀이용 별도 컷은 **연필 스케치 톤**(선만, 채색 없음).
- 페이지마다 배경·구도·시간대(점점 밝아짐)를 다르게. 같은 장면 반복 금지.
