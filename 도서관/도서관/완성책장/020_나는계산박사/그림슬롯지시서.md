# 그림 슬롯 지시서 — 나는 계산 박사 (020)

**공통 화풍:** "구름 로봇 오므리"식 부드러운 파스텔 수채, 둥근 선, 따뜻하고 포근한 분위기. 숫자와 사물(도토리·사과·잎사귀)을 귀엽게 의인화(눈·발·손). **그림 안에 글자·숫자 기호 삽입 금지.** 페이지마다 장면을 다르게.
**주인공:** 계산 박사 다람쥐 "토토" — 작은 동그란 안경, 통통한 볼, 도토리색 털, 짧은 꼬리.
**색칠 손놀이:** 각 페이지 고유 대상 1개를 연필 스케치 톤 라인아트로 제시. 굵고 둥근 외곽선, 색칠하기 쉬운 넓은 면.
