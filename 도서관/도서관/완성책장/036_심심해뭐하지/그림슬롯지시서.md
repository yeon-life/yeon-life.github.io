# 그림 슬롯 지시서 — 036 심심해, 뭐 하지?

## 공통 화풍 (모든 슬롯 동일 적용)
- 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화 톤
- 형태: 둥근 선, 둥글둥글한 형태, 따뜻하고 포근한 분위기
- 감정 표정: 페이지마다 표정을 풍부하고 다르게(따분함→궁금함→설렘→뿌듯함). 눈썹·입 모양으로 감정이 분명히 보이게
- 의인화: 지루함을 "심심이"라는 잿빛 구름 캐릭터로 의인화. 처음엔 큼직(농구공만 함)·반쯤 감긴 눈·길게 늘어진 입, 갈수록 점점 작아지고 색이 옅어짐
- 캐릭터 일관성:
  - 하린(주인공 아이): 짧은 단발, 노란 티셔츠에 초록 멜빵바지, 양말 차림. 볼이 발그레함
  - 심심이(지루함): 동그란 잿빛 회색 솜구름, 작고 졸린 눈 두 개, 늘어진 입. 크기로 감정 강도를 표현(클수록 지루함 큼)
- 금지: 그림 안에 글자·숫자 텍스트 삽입 금지
- 배경: 연한 단색 또는 부드러운 그라데이션, 여백 충분히. 비 오는 장면은 창에 빗방울만
- 구도: 페이지마다 구도·표정·원근·심심이 크기를 서로 다르게(같은 배경 반복 금지)
- 색칠 손놀이용 버전: 연필 스케치 톤(흑백 외곽선)으로도 출력 가능하게
