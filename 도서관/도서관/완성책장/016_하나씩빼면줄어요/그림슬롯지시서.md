# 그림 슬롯 지시서 — 하나씩 빼면 줄어요 (016)

공통 화풍: "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻한 빛, 포근한 질감. 숫자와 사물(풍선)을 의인화(작은 눈·볼·미소). 그림 안에 글자·숫자 표기 절대 금지. 페이지마다 장면·색감·구도를 서로 다르게. 색칠 손놀이용 라인 시트는 연필 스케치 톤(가는 회색 외곽선, 채색 없음).
