# 그림 슬롯 지시서 — 「처음 가는 학교, 두근두근」

## 공통 화풍 (모든 슬롯 적용)
- "구름 로봇 오므리"식 부드러운 파스텔 수채화. 둥근 선, 따뜻하고 포근한 분위기.
- 주인공 = 단발머리 여자아이 '다인이'(동그란 눈, 발그레한 볼, 빨간 새 가방). 모든 장면에서 같은 아이로 일관되게.
- 사물·소품 의인화 가능: 빨간 가방, 교문, 명찰 등에 작은 표정을 살짝 넣어도 좋음(과하지 않게).
- 색감: 크림빛 배경 + 파스텔 살구·민트·연보라·연노랑·하늘빛.
- **그림 안에 글자·활자 삽입 금지.** (이름표·명찰도 글자 없이 빈 패나 무늬로만)
- 페이지마다 구도·등장 인물 수·장소·시간대가 분명히 다르게(같은 배경 반복 금지).
- 손놀이(색칠) 슬롯은 연필 스케치 톤(흑백 라인), 채색 전 깨끗한 윤곽선 상태.
