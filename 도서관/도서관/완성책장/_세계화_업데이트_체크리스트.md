# 🔖 세계화 — 차후 업데이트 체크리스트

> 외국 사용자가 늘어나는 시점에 다시 꺼내 진행. (원문: 00_책프로젝트_기획/00_세계화_글로벌_작전.md §0-A2)

## 지금 확정 (기본)
- **제목 + 줄거리 요약 + 길러주는 것 = 기본 12개 언어** 미리 탑재
  한국어 · English · 中文(간체) · Español · हिन्दी · العربية · Português · Русский · 日本語 · Français · Deutsch · Bahasa Indonesia
- **전문(본문)** = 한국어 기본 + **요청 시 자동 번역 + 캐시** (우리는 한국어 원본만 제작)

## 외국 사용자 늘면 업데이트할 것
- [ ] 요약 언어 **12 → 24개 확장** (+ Italiano · Türkçe · Tiếng Việt · ไทย · Tagalog · বাংলা · اردو · Polski · Nederlands · Kiswahili …)
- [ ] **인기 언어 원어민 검수**로 격상 (자동 번역 → 검수본, 날번역 금지)
- [ ] **자주 요청되는 언어는 전문도 미리 캐시/기본화** (요청 데이터 기반)
- [ ] **RTL(아랍어 등) UI 다듬기 + CJK·데바나가리 폰트** 최적화
- [ ] **판매용 언어판 검수** + 지역 **결제·통화·세금·법(GDPR 등)** (서버·전문가)
- [ ] 트리거: 특정 언어 요청·접속이 임계치 도달 시 그 언어 우선 승격

## 판단 기준 (언제?)
- 특정 언어 접속/요청이 눈에 띄게 늘 때 → 그 언어부터 승격
- 해외 판매 시작 전 → 판매 언어판 검수 + 법·세무 확정
