# 📐 책 제작 확정 표준 (2026-06-02)

> 모든 책은 이 표준으로 만든다(001부터 통일). 제작 = 한국어 기본만, 마무리(그림·배포)는 안티그래비티.

## 1. 언어
- **기본 책 = 한국어만.** 영어·타 언어는 **요청 시 서버 AI 자동 번역 + 캐시**(우리가 미리 안 만듦).
- **단, 책당 1권은 "-샘플"** 로 한/영 완전체 데모 유지(예: `001…-샘플`).
- 줄거리 요약 12개 언어는 차후(외국 사용자 늘면).

## 1-B. ⭐ 기존 1차 텍스트 = 전면 재보수 필수
- **이미 내용이 쓰인 책(1차 텍스트: 학년 폴더·테마 시리즈 등)은 그대로 쓰지 않는다.**
- 반드시 **전면 재보수**(거의 새로 쓰는 수준의 비평·편집)를 거친다 — 구성·문장·눈높이·교육성·재미를 다시 다듬어 "정말 좋은 책"으로.
- 절차: 트리아지 채점 → 약하면 집필가가 재집필 + 검수단(검수기준표 100점)·편집장 통과. (제목만 있는 책은 처음부터 집필)
- 즉 **"기존 글 = 초안"** 으로 보고, 표준 품질로 올린 뒤에만 완성책장에 넣는다.

## 2. data.js 구조 (한국어)
```
const BOOK = {
  meta:{ badge, title, sub },
  pages:[ {label, line, art:"generic"}, ... ],     // 본문(스토리) — 유지
  message,
  grow:{ theme, desc, grade },
  activityByGrade:{ "초1~2":[3], "초3~4":[3], "초5~6":[3] },
  future:[2~3],
  gloss:{ "어간":{ read, mean }, ... }              // ⭐ 본문 의미어 거의 다(60~120), 모든 낱말 해석 목표
};
```
- gloss 어간 기준(엔진이 조사·어미 떼고 매칭). 의미어(명사·동사·형용사·부사·의태어) 빠짐없이.

## 3. 엔진 (완성본.html = `_동화책엔진/동화책엔진.html` 복사)
- 스크롤 읽기 + **스페이스·엔터 한 장씩** · 모든 낱말 클릭→읽기 · 사전 낱말 뜻+소리 · 🌐(데이터 있으면 한영 토글) · 글자 크게 · 전체 읽어주기 · 챗봇 · 학년별 활동지 · 미래사고.
- 플립북 없음(떨림 제거). 모바일 backdrop-filter 금지.

## 4. 그림슬롯지시서.md
- **페이지마다 내용에 맞는 서로 다른 그림**(같은 배경 반복 금지).
- 화풍 = 「구름 로봇 오므리」식 부드러운 파스텔 수채·둥근 선. **글자·사물 의인화.** 그림에 글자 삽입 금지.
- 색칠 손놀이 = **연필 스케치 톤**. 손놀이는 책 내용 관련.
