연라이프 최종 추천 셋 — 품질 우선, 무료에 가까운 비용

그동안 합의한 모든 결정을 한 자리에 모은 최종 추천 구성입니다. 품질을 최우선으로 두되, 똑똑한 라우팅으로 비용은 거의 무료를 유지합니다. 한 번 셋업 후 본인 컴퓨터 없이 24시간 자동 운영, 회원 1,000명까지 월 1만원 이내.

한 페이지 결론

품질은 최고급, 비용은 거의 무료 — 똑똑한 라우팅의 힘

⊕ 챗봇 메인: Claude Haiku 4.5 (한국어 1등급, 사색적 톤)

⊕ 모더레이션: Gemini Flash 무료 티어 (단순 분류 작업, 무료로 충분)

⊕ 뉴스 수집·요약: GitHub Actions + Gemini Flash 무료

⊕ 인프라: Cloudflare Workers 무료 + D1 무료 + GitHub Pages 무료

⊕ 보안: Cloudflare 무료 + Turnstile 무료 + 3단계 경고 시스템

예상 월 비용: 회원 100명 무료 → 500명 5천원 → 2,000명 2만원 → 1만명 8만원

03똑똑한 라우팅 — 비용 90% 절감의 핵심

"품질 우선이면 매번 비싼 모델 써야 하나?" 그렇지 않습니다. 질문 종류에 따라 다른 단계로 보내면 품질은 유지되고 비용만 줄어듭니다.

0단계캐시
자주 묻는 질문 30개는 미리 만든 답변을 그냥 보여줌. "화두가 뭐예요?" 같은 것.
0원
1단계FAQ 매칭
사용자 질문이 FAQ와 비슷한지 임베딩 검색으로 판단. 비슷하면 미리 만든 답.
0원
2단계일반 질문
Claude Haiku 4.5 호출. 대부분의 질문은 여기서 처리됨. 답변 품질 1등급.
약 6원/회
3단계깊은 질문
철학적·복잡한 질문에만 Claude Sonnet 4.6 호출 (선택). 자주 안 일어남.
약 80원/회
실제 트래픽 시뮬레이션 회원 500명/일, 챗봇 호출 1,500회/일 기준 분배 예상:
· 0~1단계 캐시 매칭 60% (900회) → 0원
· 2단계 Haiku 35% (525회) → 약 3,150원/일 = 95,000원/월... 너무 많아 보이지만 ↓
· 프롬프트 캐싱 90% 할인 적용 시 → 약 9,500원/월
· 3단계 Sonnet 5% (75회) → 약 6,000원/월
실제 월 합계 ≈ 1만 5천원

04회원 단계별 실제 월 비용

회원 단계 일일 사용자 일일 AI 호출 월 비용 비고
시작 ~50명 ~250회 무료 전 구간 무료 한도 내
마을 형성 ~200명 ~1,000회 약 2,000원 Gemini 무료 + Haiku 일부
마을 안정 ~500명 ~2,500회 약 8,000원 커피 두 잔 값
마을 성장 ~2,000명 ~10,000회 약 30,000원 학원 1회 강의료
큰 마을 ~10,000명 ~50,000회 약 80,000원 그때는 광고·후원으로 충당 가능
현실적 첫 1년
월 5,000원 이내
회원 500명 수준까지의 첫 1년 평균. 1년 합계 약 6만원으로 마을 전체의 AI 시스템을 운영할 수 있습니다.

05품질 보장 — 9가지 안전장치

  1. 한국어 1등급 모델만 선정 — Claude Haiku는 한국어 사색적 톤이 가장 좋다는 평가
  2. 시스템 프롬프트 정성껏 — 광장 약속·연라이프 정체성을 챗봇에게 명확히 가르침
  3. 프롬프트 캐싱 — 같은 시스템 프롬프트 재사용 시 90% 할인되며 응답도 빨라짐
  4. 관리자 검수 도구 — AI가 가린 글, 챗봇이 답한 내용을 매주 5분만 검토하면 충분
  5. 자동 폴백 — Claude 다운 시 Gemini로 자동 전환, 끊김 없음
  6. 한도 알림 — 비용 70% 도달 시 이메일, 100% 도달 시 자동 일시정지
  7. 오탐 복원 도구 — AI가 잘못 가린 글 30초 안에 복원 가능
  8. 응답 길이 제한 — 챗봇이 너무 길게 답해서 토큰 낭비하는 일 방지
  9. 1주차 데이터 튜닝 — 시작 후 1주일 운영하면서 발견된 패턴으로 프롬프트 미세 조정

06구현 순서 — 디자인 끝난 후 4~5주

1주차 — 기초 + 비용 패널 (가장 중요)

  • Anthropic Console 가입 + 결제 카드 + 월 한도 $25 설정
  • Cloudflare Workers + D1 셋업 (API 키 보호 게이트웨이)
  • 관리자 비용 모니터링 패널 가동 (이미 시안 있음)
  • 리디자인 단일 파일에서 색감·마스트헤드부터 운영 사이트에 적용

2주차 — 모더레이션 + 보안 기초

  • Gemini Flash 모더레이션 가동 (자동 숨김 + 관리자 복원)
  • Cloudflare DNS 연결 (DDoS 방어 + Turnstile 봇 차단)
  • 관리자 비밀번호 클라이언트에서 제거 (Workers로 이전)
  • DOMPurify로 XSS 방어
  • 매주 자동 백업 셋업

3주차 — 챗봇 + 메가 메뉴

  • FAQ 30개 작성 → 캐시·임베딩 검색 셋업
  • Claude Haiku 챗봇 가동 (시스템 프롬프트 + 프롬프트 캐싱)
  • 리디자인 단일 파일의 메가 메뉴를 운영 사이트에 적용
  • 좌측 하단 緣 도우미 플로팅 버튼 활성화

4주차 — 자동 뉴스 + 다듬기

  • GitHub Actions 매시간 RSS 수집 가동
  • 7개 카테고리 소스 점검 + AI 요약 셋업
  • 3단계 경고 시스템 + 감시 명단 등록 (이우주·이규민)
  • 1~3주차 데이터로 프롬프트 미세 조정

5주차 — 안전망 + 운영 매뉴얼

  • 한도 알림 이메일 + 자동 폴백 검증
  • 월 보고서 자동화
  • 2단계 인증 (관리자 OTP) 적용
  • 주민 안내 페이지·이의 신청 폼

07통합 — 한 손에 들어오는 도구 모음

모든 셋업이 끝나면 매일·매주·매월 해야 할 일이 명확해집니다.

주기해야 할 일시간
매일 관리자 대시보드 → 보안 알림 새 항목 확인 (1분) 1분
매주 비용 패널·모더 결과·챗봇 응답 표본 검토 10분
매월 Cloudflare 보안 이벤트·종속성 알림·백업 정상 작동 30분
매분기 관리자 비밀번호·API 키 회전·전체 보안 점검 1시간
총 운영 시간 한 달에 약 2시간 정도. 마을 관리에는 그 외 시간이 더 들지만, 시스템 자체 운영은 이 정도면 충분합니다.

08위험 관리 — 미리 알고 가는 것

무료 티어 정책 변동 구글이 2025년 말 Gemini 무료 한도 50~80% 줄인 사례 있음. 무료에 의존하지 말고, 매월 사용량 점검하고 폴백 구축. 이번 셋은 폴백 두 단계(Gemini → Groq → Cerebras)까지 자동 전환되도록 설계.
AI 오탐 모더가 학생의 서툰 질문이나 한자 인용을 잘못 가릴 수 있음. 자동 삭제 X, 자동 숨김 + 관리자 30초 복원. 매주 검토로 패턴 학습.
비용 통제 Anthropic 콘솔 월 한도 $25 + 자체 알림 시스템 + 100% 도달 시 자동 Gemini 폴백. 세 겹 안전장치로 청구서 폭탄 방지.
운영자 한 명에 의존 연소사님 한 분의 손에 모든 것이 달려 있음. 1~2년 안에 신뢰할 만한 부운영자(인증된 선생님 등)를 한두 명 더 확보하면 마을이 단단해짐.
최종

"품질 우선"과 "거의 무료"는 양립 가능합니다.

핵심은 똑똑한 라우팅과 무료 티어 적극 활용입니다.

· 단순한 작업(모더레이션·뉴스 요약)은 무료 Gemini로

· 중요한 답변(챗봇)은 한국어 1등급 Claude Haiku로

· 드물게 깊은 질문은 Claude Sonnet으로 (옵션)

· 인프라(호스팅·게이트웨이·DB·자동화·보안)는 전부 무료 티어

· 프롬프트 캐싱·FAQ 캐시로 비용 90% 절감

결과: 회원 500명까지 월 1만원 이내. 1년 평균 5천원/월. 마을 전체의 따뜻한 AI 시스템이 카페 한 잔 값으로 운영됩니다.
