1-2. 세계는 지금 (확장 예정)

각 나라의 진짜 보도된 기사를 한국의 시선으로 해설. 본문 전문 복제 절대 금지

단계국가별 기자특이 사항
1단계10국 × 1명한 사람이 그 나라 모든 분야 커버
2단계인기 국가 분야별예: 미국 정치·경제·문화 각 1명
3단계50명 풀매체 라이선스 협의 동시 진행

10개국 후보: 미국 · 일본 · 중국 · 영국 · 프랑스 · 독일 · 베트남 · 인도네시아 · 인도 · 브라질

1-3. K-Wave 다국어 (역방향)

  • 1단계: 영어 · 일본어 · 베트남어 (3개)
  • 2단계: 중국어 · 인도네시아어 · 태국어 추가 (총 6개)
  • 3단계: 풀 10개 언어

전문 영역: K-pop · K-드라마 · K-푸드 · K-뷰티 · 한국 시·고전. 가십이 아닌 “왜 지금 K가 사랑받는지 한국의 자리에서 설명” 톤.

1-4. 글로벌 마켓 시그널

  • 임팩트 점수 1~10 매김, 9점 이상만 메인 카드에 진입
  • “투자 조언이 아닙니다 · 본인 책임” 면책 자동 삽입
  • 종목 단정 추천 금지 실시간 가격 직접 표시 X

2 · 자율 운영 (자동화)

2-1. 신뢰 점수 자동 분류

신뢰 점수주제처리
≥ 0.85일반(과학·문화·환경·울산 등)검수 없이 자동 발행
0.70 ~ 0.85일반검수 큐 (미승인 24h 후 자동 발행)
< 0.70 또는 민감정치·의료·금융 단정·실명검수 큐 필수 (미승인 시 자동 폐기)

평균 일 13편 중 8~10편 자동, 3~5편만 검수 큐.

2-2. 부재 모드 (Vacation Mode)

여행·휴식 시 토글 하나로 모든 신뢰 ≥ 0.70 글이 자동 발행. 민감 주제만 큐 보관. 복귀 시 자동 요약 리포트.

상황자동 대응
API 비용 월 한도 80% 도달자동 일시 정지 + 알림
매체 RSS 24h 응답 없음그 매체 제외, 대체 매체로 자동 전환

6 · 저작권 안전선 (반드시 준수)

  1. 외국 매체 기사 전문 번역 게재 절대 금지
  2. 인용은 2~3문장(또는 1~3문단) 이내, 원문 링크 의무
  3. 우리 본문 = 우리 톤의 해설·맥락화, 단순 번역 X
  4. OG 이미지·기사 사진은 매체 라이선스가 명시된 경우만, 폴백은 자체 생성
  5. 사람 얼굴 AI 생성 금지 (정치인·종교 지도자·미성년 포함)
  6. AI 페르소나의 글에 매 회 AI 작성 라벨 + 면책 문구 자동 삽입
  7. 의료·법률·금융 단정 금지, 전문가 상담 권고 자동 삽입
이 규칙은 사이트가 자라기 시작하면 매체와 라이선스 협의로 일부 완화 가능. 그 전까지는 예외 없음.

7 · 공정성 정책 + 핵심 마케팅 포커스 ★

"같은 사건, 세 시선으로."
한쪽으로 기울지 않도록 설계된 매일의 뉴스

7-1. 핵심 포지셔닝

색깔 논쟁에 지친 한국 독자에게 차분한 다층 시선을 제공한다. 이것이 연라이프의 핵심 차별점이다.

7-2. 정직한 경계 (마케팅의 함정 피하기)

❌ 약한 메시지 (피하기)✅ 강한 메시지 (가기)
"AI 가 만든 공정한 뉴스""한쪽으로 기울지 않도록 매일 점검합니다."
"객관적입니다""같은 사건, 세 시선으로."
"편향이 없습니다""편향을 숨기지 않고 드러냅니다 — 인용 비율 미터."
이유: AI 는 학습 데이터·프롬프트에 편향이 들어간다. "AI = 공정" 마케팅은 학계·언론학자의 강한 비판을 받는다. 실제 미국에서도 "AI 뉴스 = 객관" 으로 광고한 매체들이 거꾸로 신뢰를 잃었다.

왜 이 순서인가

  • 화두가 1번 — 연라이프의 정체성. 어떤 뉴스보다 “먼저 멈춰 서는 자리”가 최상단.
  • 우리나라 → 세계 순 — 한국 독자의 일상 우선. 우리나라부터 봐야 세계가 보인다.
  • 광장이 뉴스 다음 — 받기만 하지 않고 함께 묻는 자리가 뉴스 바로 다음.
  • 사설은 가장 깊은 자리 — 그날의 결을 마무리하는 글. 스크롤 끝까지 읽은 사람이 만난다.

9 · 동적 국가 + 3 카테고리 + 신뢰도 8축 ★ 4차 확정

9-1. 10국 고정 폐기 → "분야 페르소나 + 동적 무대"

변경 전변경 후
10국 × 1명 고정 페르소나분야 페르소나 13명 유지, 글의 무대(나라)는 매일 자유롭게
"그 나라 전담 기자" 친밀감분야 페르소나가 그 사건의 무대를 자유롭게 다룸

추가로 "오늘의 시선 — Country of the Day" 신설. 매일 임팩트 점수 ≥ 8 사건의 나라 1~2곳 자동 선정. 어제 케냐 → 오늘 폴란드 → 내일 인도네시아 식으로 표지가 바뀜.

9-2. 메인 카테고리는 3축 — 증시는 메인 아님

카테고리정의톤
좋은 소식 · 따뜻한 자리인류·생명·환경에 긍정적 변화살구·따뜻한 종이톤
꼭 알아야 할 소식영향력 크고 보편적, 정치 색채 옅음차분한 청록
주의할 소식 · 깊이 보는 자리위험·경고·시스템 리스크진한 살구
증시는 별도 전문 코너 (글로벌 마켓 시그널)로 분리. 메인 3카테고리에는 자연스럽게 섞임 — 증시 폭락은 "주의할 소식"에 등장.

9-3. 신뢰도 평가 — 8축 (단순 카운트 폐기)

"3곳 동시 보도 = 신뢰" 폐기. 한국 언론 환경에선 받아쓰기·풀(Pool) 보도·진영 카르텔로 신뢰의 근거가 되지 못함.
#축가중치평가 방식
1출처 다양성15%같은 자본·소유 그룹은 1개로 카운트. 진영 균형 보너스.
21차 출처 인용20%공식 발표·논문·판결문·통계 직접 인용 ↑. 익명 일색 ↓.
3검증 가능성15%독자가 직접 원자료에 접근할 링크 N개 ↑
4시간 검증10%24~72시간 후 정정·반박 없이 유지
5이해 충돌10%매체와 사건 당사자의 광고·자본·후원 관계
6팩트체커 교차15%SNU·JTBC·한겨레·Reuters·AP 팩트체크 일치
7언론자유 가중10%RSF(국경없는기자회) 자유지수
8아카이브 일관성5%Wayback Machine 캡처 + 수정 이력 추적

최종 신뢰 점수 = Σ(축 점수 × 가중치). 0~100점.

점수처리
≥ 80검수 후 자동 발행 + 상단 강조 가능
70 ~ 79검수 후 자동 발행
50 ~ 69검수 큐 필수 (24h 미승인 자동 폐기)
< 50자동 폐기
정치·종교·실명점수 무관 항상 검수 큐
처음 등장 매체점수 무관 검수 큐 + 매체 평가 등록

9-4. 투명성 — 신뢰도 평가 100% 공개 ★

모든 글 하단에 자동으로 신뢰도 미터 삽입. 누르면 8축 세부 점수 펼침. 인용 매체 목록·진영 균형·신고 버튼 포함.

별도 공개 페이지: 신뢰도_평가_정책.html — 일반 독자에게 100% 공개. 산식·가중치·매체 평가 DB·우리가 인정하는 한계까지 모두 명시.

핵심 자세 — "우리 점수가 진실이다" 가 아니라 "우리가 어떻게 점수를 매겼는지 공개한다" 가 우리 약속.

9-5. 마케팅 자산 (추가)

  • 홈 카피 후보: "점수만 보여주지 않습니다. 점수가 어떻게 매겨졌는지도 보여드립니다."
  • 보도자료 한 줄: "AI 신뢰 점수를 공개한 첫 한국어 미디어"
  • 글 상단 배지 확장: <인용 매체 N곳 · 균형 점수 ★★★★☆ · 신뢰도 73/100>
