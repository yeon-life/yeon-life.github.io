각자의 우주에 별이 모이는 곳 — 개인 생각의 지도

방문자가 마을을 거닐다 마음에 닿는 것을 즉시 스크랩하고, 그것들이 자기 우주에서 별처럼 연결되어 사유의 지형이 되는 시스템. 뉴스든, 광장의 글이든, 챗봇과 나눈 한 마디든 — 무엇이든 스크랩되고 연결됩니다.

설계 철학

"읽기"를 "쌓기"로, "쌓기"를 "사유"로

SNS는 손가락이 다음 글로 흘려보내는 도구입니다. 연라이프는 반대 방향을 봅니다.

마음에 닿은 한 줄을 멈춰 세워 자기 우주에 별로 놓아두고, 시간이 지나면서 그 별들이 별자리가 되어 자기 사유의 지형을 만듭니다. 각 주민이 1년이 지난 후, 자신만의 작은 도서관 — 별자리 같은 생각의 지도 — 를 갖게 됩니다.

이것은 연라이프 약속의 가장 깊은 실현입니다 — "여기서 쓴 모든 것은 당신의 자산입니다."

01어디서 스크랩할 수 있나 — 다섯 자리

마을의 모든 자리에서 스크랩 버튼이 자연스럽게 나타납니다.

소식·뉴스

뉴스 기사를 스크랩

7개 카테고리에서 마음에 닿은 기사. 한 줄 요약·원문 링크가 자동으로 함께 저장됩니다.

"태화강 봄철 수질 시민과학자 측정" — 5월 13일 우리동네

광장

광장 글·댓글을 스크랩

아골라·아곤란의 글 전체나 마음에 닿는 한 문단·한 댓글만 골라서.

"멈춤이 자유라는 말이 한참 머물게 합니다." — 박주민의 댓글

챗봇 대화

緣 도우미와의 대화를 스크랩

챗봇이 답한 좋은 한 마디나 대화 한 토막을 그대로.

"좋은 물음은 답을 찾는 게 아니라 나를 바꾸는 일입니다."

블로그

주민 블로그 글을 스크랩

다른 주민의 블로그 글·인용구·사진까지. 작가에게 자동으로 "스크랩됐어요" 알림 발송(선택).

"맹자의 不忍人之心과 거울 뉴런" — 최영재의 서고 No.011

내 메모

내 머릿속 한 줄을 스크랩

어디서 가져온 게 아니라 내가 생각한 한 줄도 별이 됩니다. 매일 한 줄씩 쌓으면 1년 후 366개의 별.

"오늘 학생의 질문이 내 답변보다 깊었다."

02스크랩 한 번의 흐름

사용자가 글을 읽다 마음에 닿는 한 문단 발견 ↓ 문단을 마우스로 선택 (또는 모바일은 길게 누름) ↓ 떠오르는 작은 버튼: "+ 스크랩" (호박색 알약) ↓ 클릭하면 즉시 별이 됨 (애니메이션 0.3초) ↓ 선택: 한 줄 노트 추가? · 태그 붙이기? · 그냥 저장? ↓ 내 생각의 지도에 별로 추가됨 ↓ AI가 자동으로 "관련 있는 다른 스크랩" 제안 ↓ 선택: 별 사이 선 연결 · 다음에 → "전체 보기 →"

스크랩 버튼의 두 상태

"...의식과 행위 사이 0.3초의 간극이..."
"...의식과 행위 사이 0.3초의 간극이..."

평소엔 거의 안 보이게, 마우스를 갖다 대면 부드럽게 떠오릅니다.

03내 생각의 지도 — 별자리 페이지

스크랩한 모든 것이 한 페이지에 별로 떠 있는 자기만의 우주. 이미 광장 생각의 지도와 같은 시각 언어를 씁니다.

임선생의 생각의 지도
23개의 별, 14개의 연결 · 2026년 5월
광장 글   뉴스   챗봇   블로그   내 메모

별의 모양과 색

  • 크기 — 자주 다시 읽는 별일수록 커짐 (마음의 무게)
  • 색 — 스크랩 출처에 따라 (광장=틸, 뉴스=호박, 챗봇=초록, 블로그=빨강, 내 메모=보라)
  • 연결선
    • 실선 — 내가 직접 연결한 별 사이
    • 점선 — AI가 "이 둘이 비슷합니다" 제안한 별 사이 (수락하면 실선으로)
  • 위치 — 시간순/주제별/자유 배치 중 선택. 본인이 직접 끌어다 놓을 수도

지도와 함께 가능한 것

  • 검색 — 키워드로 별 찾기
  • 필터 — "뉴스만", "최근 1주", "태그=교실" 등
  • 타임라인 모드 — 별들을 날짜순으로 다시 배치
  • 주제별 모드 — AI가 태그/내용으로 자동 군집
  • 여행 모드 — 별을 하나씩 클릭하며 다시 읽기 (자기 사유의 산책)

04데이터 구조

Cloudflare D1 (무료 5GB) 에 저장. 회원당 평균 1년에 ~500개 스크랩 가정, 1만 회원까지 충분.

// Cloudflare D1 — scraps 테이블 CREATE TABLE scraps ( id TEXT PRIMARY KEY, -- UUID user_id TEXT NOT NULL, -- 회원 ID type TEXT NOT NULL, -- 'news'|'plaza'|'chatbot'|'blog'|'self' -- 원본 정보 source_url TEXT, -- 원문 링크 (있으면) source_title TEXT, -- 원본 제목 source_author TEXT, -- 원본 글쓴이 source_date DATETIME, -- 원본 작성일 -- 스크랩 내용 content TEXT NOT NULL, -- 실제 스크랩한 텍스트 my_note TEXT, -- 내가 쓴 한 줄 메모 tags TEXT, -- JSON 배열: ["철학","교실"] -- 지도 위치 x REAL, y REAL, -- 별의 위치 (자동/수동) size REAL DEFAULT 1, -- 별 크기 (다시 읽을수록 커짐) -- 메타 created_at DATETIME DEFAULT CURRENT_TIMESTAMP, last_visited_at DATETIME, visit_count INTEGER DEFAULT 0 ); // 별 사이 연결 CREATE TABLE connections ( id TEXT PRIMARY KEY, user_id TEXT NOT NULL, scrap_a TEXT NOT NULL, scrap_b TEXT NOT NULL, kind TEXT, -- 'manual'|'ai_suggested' note TEXT, -- 왜 연결되어 있는가 created_at DATETIME DEFAULT CURRENT_TIMESTAMP ); // 인덱스 (속도) CREATE INDEX idx_scraps_user ON scraps(user_id, created_at); CREATE INDEX idx_conn_user ON connections(user_id);

05AI가 도와주는 일

AI는 명령자가 아닌 도우미입니다. 늘 제안만, 결정은 본인이.

AI가 도와주는 일어떻게 작동사용 모델
자동 태그 제안 스크랩 내용 보고 적절한 태그 3~5개 제안. 수락/거절 본인이. Gemini Flash (무료)
연결 제안 새 스크랩이 기존 별 중 어느 것과 비슷한지 임베딩 비교. "이 둘이 닮았어요" 제안. Gemini 임베딩 (무료)
주제별 군집 20개 이상 별 모이면 "이 별들은 '자유의지'에 관한 것 같습니다" 같은 군집 제안. Gemini Flash (무료)
월간 요약 매월 1일 "지난 한 달간 당신이 자주 머문 주제는..." 같은 자기 사유 요약. Claude Haiku
여행 추천 "오늘 별 하나만 다시 읽고 싶다면..." 매일 한 별 추천 (시간이 지난 옛 별 위주). Gemini Flash (무료)

06내보내기 — "내 자서전"으로 가는 길

연라이프 로드맵에 있는 자서전 공방 (2027 예정)의 기반이 바로 이 스크랩북입니다. 1년치 별을 모아 한 권의 책으로 묶을 수 있어요.

네 가지 내보내기 형식

  • 📄 PDF — 시간순/주제순 깔끔한 책 형태. 인쇄도 가능
  • 📝 마크다운 — 다른 노트 도구(Obsidian·Notion 등)로 옮기기 좋음
  • 🌐 정적 HTML — 본인 도메인에 올려서 자기 별자리 영원히 보관
  • 🖼️ 별자리 이미지 — 지도를 그대로 PNG로 — 인쇄해서 책상 위에

2027 자서전 공방 연결

1~2년치 스크랩이 쌓이면 자서전 공방에서 그 별들을 토대로 자전적 글쓰기를 도와줍니다. AI가 별 사이의 패턴을 보고 "당신은 이런 시기에 이런 주제에 자주 머물렀어요"를 알려주고, 그 패턴을 기반으로 한 챕터 한 챕터 함께 써 나가는 도구.

"기록하지 않은 생각은 정말 내 생각이라고 할 수 있을까?" 이게 우리가 만든 화두 중 하나였습니다. 이 시스템은 그 화두에 대한 연라이프의 답이 됩니다 — 기록할 수 있는 자리를 마을이 마련합니다.

07개인정보와 신뢰 — 약속

  • 전적으로 비공개 — 본인 외 누구도 다른 사람의 지도를 볼 수 없음 (운영자도 X)
  • 선택적 공개 — 본인이 원하면 "별 하나"만 공개해서 광장에서 나누기 가능
  • 탈퇴 시 완전 삭제 — 회원 탈퇴 시 모든 스크랩 영구 삭제
  • 다운로드 권리 — 언제든 본인 데이터 전체를 ZIP으로 받을 수 있음
  • AI 처리 투명성 — 어떤 AI가 무엇을 처리하는지 설정에서 확인 가능, 끄기 옵션
  • 저작권 — 다른 주민의 글 스크랩 시, 원작자에게 자동 알림(선택). 외부 뉴스는 링크·요약만

08UI에 추가될 곳들

스크랩 버튼이 나타나는 자리

  • 뉴스 카드 — 카드 우측 상단에 "+ 스크랩" 작은 알약 버튼
  • 광장 글 상세 페이지 — 문단 선택 시 떠오르는 툴팁 ("+ 스크랩")
  • 댓글 — 댓글 우측에 작은 스크랩 아이콘
  • 챗봇 응답 — 챗봇 답변 끝에 "이 답 스크랩하기" 링크
  • 블로그 글 — 글 옆에 떠 있는 사이드 버튼

새로 만들 페이지 / 패널

  • 내 생각의 지도 페이지 — 별자리 시각화 + 검색·필터 (광장 생각의 지도와 같은 시각 언어)
  • 스크랩북 리스트 뷰 — 카드 형태 목록 (지도가 부담스러운 사람 위해)
  • 별 상세 모달 — 별 클릭 시 펼쳐지는 카드 (내용·노트·태그·연결·편집)
  • 스크랩 패널 (우측) — 이미 외부 디자인에 들어 있음 (YLScrapbook.jsx) — 이걸 확장

마스트헤드 / 메뉴 추가

  • 마스트헤드 우측: "내 생각의 지도" 작은 별 아이콘 (✦)
  • 차림표(메가 메뉴): 블로그 카테고리 안에 "내 생각의 지도" 추가
  • 모바일: 하단 탭바에 "지도" 탭 (있으면)

09구현 — 어떤 순서로

1단계 — 기본 스크랩 (2주)

  • D1 테이블 생성 (scraps, connections)
  • 스크랩 버튼 디자인 (호박색 알약, 부드러운 등장 애니메이션)
  • 5개 자리에 스크랩 버튼 추가 (뉴스·광장·댓글·챗봇·블로그)
  • 리스트 뷰 우선 (지도는 다음 단계) — 외부 디자인의 YLScrapbook.jsx 활용
  • 한 줄 노트·태그 추가 가능

2단계 — 별자리 지도 (3주)

  • D3.js 또는 vis-network로 별자리 시각화
  • 광장_생각지도.html과 같은 시각 언어 (어두운 우주 톤)
  • 줌·드래그·검색·필터
  • 별 클릭 → 상세 모달

3단계 — AI 보조 (2주)

  • 자동 태그 제안 (Gemini)
  • 임베딩 기반 연결 제안
  • 주제별 군집 (별 20개 넘으면)

4단계 — 내보내기·자서전 연결 (2주)

  • PDF·마크다운·HTML·이미지 내보내기
  • 월간 요약 자동 메일 발송
  • 자서전 공방 시안(2027 예정과 연결)

총 9주 — 디자인 적용 후 약 두 달

지금 정해둔 4주 AI 로드맵에 이어서 추가 5주 분량. 즉 디자인 후 3개월 전후에 완성.

"각자의 우주에 별이 모이는 곳" — 이게 연라이프의 깊이가 됩니다.

이 기능 하나가 추가되면, 연라이프는 더 이상 "토론 사이트"가 아니라 "사유의 도구"가 됩니다.

SNS와 결정적으로 다른 자리 — 빨리 흘려보내는 곳이 아니라 천천히 모이는 곳.

1년 후 주민이 자기 별자리를 펼쳐 봤을 때 — "이게 나구나" 하고 마음이 깊어지는 자리.
