Week 1 · 5월 18~24일 (예시)

기초 셋업 + 비용 모니터링

먼저 인프라부터. AI 기능은 아직 없어도, "얼마 쓸지 안 쓸지"부터 보이는 구조를 만든다.

①계정·키 발급

  • Anthropic Console 가입 (console.anthropic.com) · API 키 발급 · 결제 카드 등록 (Claude는 무료 티어 없음, 사용량만큼 청구) 15분
  • 월 사용량 한도 설정 — Anthropic 콘솔에서 "Monthly spend limit" $25 (약 33,000원)로 설정. 한도 넘으면 자동 차단됨 5분
  • Cloudflare 가입 + Workers 활성화 · 무료 플랜 10분
  • Cloudflare D1 데이터베이스 생성 — SQLite 형식, 무료 5GB. 호출 로그 저장용 10분
  • 기존 Gemini API 키 재확인 — 연라이프에 이미 있음 5분

②Cloudflare Workers 게이트웨이 셋업

  • Worker 프로젝트 생성 — y-life-ai-gateway 15분
  • 환경변수에 API 키 저장: ANTHROPIC_API_KEY, GEMINI_API_KEY (브라우저 노출 X) 10분
  • 기본 라우팅 작성: /api/chat (Claude로) + /api/moderate (Gemini로) 1시간
  • 호출 로그 D1에 기록: 시간·기능·모델·입력 토큰·출력 토큰·비용 1시간
  • 로컬 테스트 — curl로 두 엔드포인트 모두 응답 확인 30분

③비용 모니터링 패널 (관리자 대시보드)

  • 관리자 페이지에 "AI 비용" 메뉴 추가 20분
  • 비용 집계 엔드포인트: /api/admin/cost-summary — D1 쿼리해서 일별·모델별·기능별 집계 1시간
  • 패널 HTML 적용: AI비용패널_관리자대시보드_시안.html 그대로 사용 2시간
  • 실시간 갱신 — 1분마다 자동 새로고침 또는 수동 새로고침 버튼 30분
이번 주 산출물
  • Cloudflare Workers 게이트웨이 — /api/chat, /api/moderate 작동
  • 호출 로그 데이터베이스 — 모든 AI 호출이 자동 기록됨
  • 관리자 AI 비용 패널 — 실시간 비용·사용량 확인
  • API 키 안전하게 보호된 상태
검증 방법
  • 관리자 대시보드 → AI 비용 메뉴 클릭 시 패널이 정상 표시
  • 테스트 호출 5번 후 로그에 5건 기록
  • 브라우저 개발자 도구에서 API 키가 노출 안 됨

02
Week 2 · 5월 25~31일

모더레이션 시스템 작동

광장 약속(말에는 마음씨가 그대로 담깁니다)을 AI가 지키는 첫 번째 일. 자동 숨김 + 관리자 복원.

①모더레이션 규칙 정리

  • 광장 약속 정식 문서화 — 좋은 글 / 숨길 글 각각 10개 예시 2시간
  • 점수 기준 정의 — 0~5점, 자동 숨김 임계값 2점 이하 1시간
  • 시스템 프롬프트 작성 — Gemini Flash에 전달할 정확한 지시문 2시간
  • 20개 샘플로 테스트 — 진짜 글 5개 + 가짜 도배 5개 + 학생 글 5개 + 어려운 케이스 5개 1시간

②게시판에 자동 모더레이션 붙이기

  • 글 등록 흐름 수정 — 글 작성 → Cloudflare /api/moderate → 점수 받음 → DB에 저장 2시간
  • 숨김 표시 추가 — 점수 2점 이하면 hidden: true 플래그, 일반 사용자에게 안 보임 1시간
  • 로딩 UX — 글 등록 시 "검토 중..." 1~2초 표시 후 정상 게시 30분
  • 모더 결과 기록 — 비용 패널에 "오늘 N건 검토, M건 숨김" 표시 1시간

③관리자 복원 도구

  • "AI가 숨긴 글" 목록 페이지 — 관리자만 볼 수 있음 2시간
  • 각 글마다 정보 표시 — AI 점수, 판정 이유, 카테고리, 작성자 1시간
  • 복원·삭제·예외 처리 버튼 — 한 번 클릭으로 복원 1시간
  • 학습 피드백 — 잘못 숨긴 글 복원 시 그 사례를 시스템 프롬프트에 추가 검토 설계 미루기
이번 주 산출물
  • 자동 모더레이션 작동 — 모든 새 글이 AI 검토 거침
  • 품격 낮은 글 자동 숨김 — 일반 사용자에게 안 보임
  • 관리자 복원 도구 — 오탐 복구 30초 안에 가능
  • 모더 활동이 비용 패널에 반영
검증 방법
  • 정상 글 5개 작성 → 모두 표시
  • 욕설·도배 글 5개 작성 → 모두 자동 숨김
  • 관리자에서 "숨김 글" 페이지 정상 표시
  • 복원 버튼 작동 확인
이번 주 비용
0원
Gemini Flash 무료 한도(1,500/일) 내 운영. 일 평균 50건 정도 예상.
오탐 주의 AI는 동양사상의 한자 인용, 학생의 서툰 질문, 깊은 인용구를 "의미 없음"으로 잘못 판단할 수 있습니다. 첫 주는 "자동 삭제"가 절대 아닌 "자동 숨김 + 관리자 확인"으로 가동. 일주일 데이터 쌓이면 기준 조정.

Week 3 · 6월 1~7일

챗봇 — 사이트의 모든 궁금증 응답

방문자가 사이트에 대해 묻는 모든 것에 답하는 따뜻한 챗봇. Claude Haiku로 한국어 한 톤 깊게.

①지식 베이스 정리

  • FAQ 마크다운 작성 — 자주 물을 만한 30가지 질문과 답 3시간
  • 약관·운영 원칙·광장 약속 정리 1시간
  • 이 주의 화두 동적 주입 — 챗봇이 "이번 주 화두 알려줘" 답할 수 있게 1시간
  • 인연의 다리 (생태계) 정보 — 연마을·수풀AI 등 소개 30분

②챗봇 시스템 프롬프트 설계

  • 역할 정의 — "당신은 연라이프 안내자 '연이'. 따뜻하고 사색적인 톤" 1시간
  • 대답 원칙 — 비교 프레임 X, 학생도 어른도 친절히, 답을 모르면 솔직히 1시간
  • 지식 베이스 컨텍스트 주입 — 시스템 프롬프트에 FAQ·약관 포함 1시간
  • 응답 길이 제한 — 보통 2~4문장, 길어야 7문장 30분
  • 10개 질문으로 테스트 — 톤·정확도·길이 2시간

③플로팅 챗봇 UI

  • 우측 하단 챗봇 버튼 — 緣 아이콘, 살짝 떠올라 있는 느낌 1시간
  • 대화창 디자인 — 새벽의 신뢰 팔레트, 세리프 본문 2시간
  • 대화 히스토리 — 브라우저 localStorage에 저장, 페이지 이동해도 유지 1시간
  • 모바일 반응형 — 폰에서는 전체 화면으로 펼침 1시간
  • "답을 못 찾으면 편집인에게 문의" 폴백 30분
이번 주 산출물
  • 플로팅 챗봇 작동 — 모든 페이지에서 사용 가능
  • FAQ 30개 답변 가능 — 사이트 이용·운영 원칙·기능 설명
  • 이 주의 화두 동적 답변 — 매주 자동 갱신
  • 챗봇 비용이 비용 패널에 자동 기록
검증 방법
  • "아골라랑 아곤란 차이가 뭐예요?" → 정확한 답
  • "이번 주 화두는?" → 현재 화두 답
  • "내 블로그 시작하는 방법?" → 안내
  • "좋은 물음이 뭔가요?" → 마음씨 살린 답
  • "날씨 어때?" → "사이트 외 질문은 안 다룬다"고 정중히 답
이번 주 비용
2,000원
Claude Haiku 호출 ~200건 (테스트 + 초기 사용)
프롬프트 캐싱 활성화 Claude의 prompt caching 기능을 켜면, 같은 시스템 프롬프트(지식 베이스) 재사용 시 90% 할인됩니다. 챗봇은 같은 시스템 프롬프트를 항상 쓰므로 이걸 켜는 게 매우 큰 절약입니다. Anthropic 문서 참조.

  • 모더 오탐·미탐 검토 — 잘못 숨긴 글 / 놓친 글 사례 수집 2시간
