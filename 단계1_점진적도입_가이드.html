색감과 마스트헤드만 먼저 입히기

운영 중인 index.html의 기능(관리자 대시보드, AI 도우미, 게시판 동기화, 로그인)은 그대로 두고, 가장 위쪽 보이는 부분 두 곳만 v4 색감·마스트헤드로 교체합니다. 잘못되어도 되돌리기 쉽고, 효과는 즉시 눈에 보입니다.

⚠ 시작 전 백업 index.html을 통째로 복사해 두세요. 파일 이름은 index_backup_2026-05-14.html 추천. 잘못되면 이 파일로 즉시 되돌립니다.

변경 1CSS 변수 교체 (색감)

index.html 의 <style> 블록 맨 위에 있는 :root 변수를 아래 토큰으로 교체합니다. 기존 변수 이름과 충돌하지 않도록 새 이름(--yl-*)을 씁니다. 본문 색·배경만 새 토큰을 참조하게 합니다.

붙여넣을 코드 (style 블록 최상단)

/* y-life.kr 새벽의 신뢰 팔레트 — v4 */ :root { /* Core */ --yl-ink: #1a2326; /* 본문 텍스트 */ --yl-soft: #2a3438; --yl-teal: #2a5358; /* 1차 강조 */ --yl-teal-mid:#4a6878; /* 2차 강조 */ --yl-amber: #a87b3e; /* 액센트 */ /* Lines */ --yl-line: #d8d3c7; --yl-fine: #e8e4d9; /* Text */ --yl-muted: #5e6a6e; --yl-soft-c: #8a9398; /* Surfaces */ --yl-paper: #f4f0e6; --yl-warm: #f6f3ec; --yl-cool: #eee9dc; --yl-surface:#fbfaf5; /* Fonts */ --yl-serif: "Noto Serif KR", serif; --yl-sans: "Pretendard", "Apple SD Gothic Neo", sans-serif; }

본문 색·배경 적용

같은 <style> 안에 다음 한 줄을 추가합니다. 기존 body 스타일 끝에 덧붙이면 됩니다.

body { /* 기존 스타일 유지 + 아래 두 줄만 추가/덮어쓰기 */ background: linear-gradient(180deg, var(--yl-warm) 0%, var(--yl-paper) 60%, var(--yl-cool) 100%); color: var(--yl-soft); font-family: var(--yl-sans); }

구글 폰트 로드 (head 안)

<!-- <head> 안에 추가 --> <link href="https://fonts.googleapis.com/css2?family=Noto+Serif+KR:wght@400;500;700&display=swap" rel="stylesheet"> <link href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css" rel="stylesheet">

주의건드리지 말아야 할 곳

아래 영역은 기능과 직결되어 있어서 1단계에서는 그대로 둡니다. 단계 4(메가 메뉴 통합)에서 한꺼번에 다룹니다.

  • 관리자 대시보드 진입 로직 (관리자 모드 버튼, 관리자 비밀번호)
  • 게시판 동기화 코드 (지금 동기화, 공유 게시판 ID 처리)
  • 로그인·회원가입 모달 자체 (외형은 단계 3에서 입힘)
  • 구글 OAuth 로직, Gemini API 호출
  • 화두 편집·예약 로직
  • AI 도우미 플로팅 버튼의 동작

실행적용 순서 체크리스트

  • 0단계 — 백업: 현재 index.html을 index_backup_2026-05-14.html로 복사
  • 1단계 — 폰트: <head>에 구글 폰트 두 줄 추가
  • 2단계 — CSS 변수: :root에 --yl-* 토큰 추가 (기존 변수 삭제 X)
  • 3단계 — body 색: body의 background·color·font-family를 --yl-*로 덮어쓰기
  • 4단계 — 마스트헤드 CSS: .yl-topbar ~ .yl-masthead 클래스 추가
  • 5단계 — 마스트헤드 HTML: body 시작 부분의 기존 상단을 새 마스트헤드로 교체
  • 6단계 — 로컬 테스트: 브라우저에서 열어 화두/소식/광장/관리자 모드 모두 작동하는지 확인
  • 7단계 — 모바일 테스트: 폰 폭에서 마스트헤드 깨지지 않는지
  • 8단계 — 배포: GitHub에 push (메모리 기준 main 브랜치)
되돌리기 문제 발견 시 index_backup_2026-05-14.html을 index.html로 덮어쓰고 다시 push 하면 즉시 원상복구.
예상 변화 배경이 푸른 기 머금은 아이보리로 바뀌고, 상단 로고가 큰 세리프로 변하며, 우측 상단에 "내 블로그" 진입 버튼이 새로 생깁니다. 본문 내용·기능은 그대로입니다.
