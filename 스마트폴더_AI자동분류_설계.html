스마트 폴더 — AI가 정리해주는 자기 서랍장

별자리 지도는 시각적 사유의 자리. 그 옆에 정리된 서랍장이 같이 있으면 더 좋아요. 스크랩을 하면 AI가 가장 어울리는 폴더를 자동으로 제안하고, 새 분류가 필요한 순간이 오면 새 폴더도 자동으로 만들어집니다. 전체 보기·폴더 보기·태그 보기·지도 보기 — 본인의 마음에 맞는 결로.

설계 원칙

"가지런하되 갇히지 않는다"

폴더가 너무 강하면 답답하고, 폴더가 없으면 어지럽습니다. 좋은 정리는 강제하지 않으면서 길을 안내하는 것입니다.

이 시스템은 그래서 — 폴더는 AI가 부드럽게 제안만 하고, 같은 별이 동시에 여러 폴더에 있을 수도 있고, 폴더 무시하고 전체로 펼쳐 볼 수도 있고, 별자리 지도로 펼쳐 볼 수도 있습니다.

주민은 자기 결에 맞는 보기 방식을 매번 고르면 됩니다.

04AI 자동 분류 — 어떻게 가장 좋은 폴더를 찾나

매번 스크랩 시 (실시간)

  1. 새 스크랩의 임베딩 벡터 계산 (Gemini 임베딩, 무료)
  2. 각 기존 폴더의 "대표 벡터"와 코사인 유사도 비교
  3. 가장 높은 두 폴더가 제안됨 (유사도 % 함께)
  4. 모두 60% 미만이면 → "새 폴더 만들기" 제안
  5. 사용자가 선택한 폴더 → 그 폴더 대표 벡터 갱신

매월 자동 정리 (배치)

  1. 전체 별들을 K-means 또는 HDBSCAN으로 자동 군집화
  2. 현재 폴더 구조와 비교 → 차이점 찾기
    • 한 폴더 안에 두 군집 → "분할 제안"
    • 두 폴더가 한 군집 → "병합 제안"
    • 고립된 별들 → "정리되지 않음으로 이동" 제안
  3. AI가 자연어로 제안 작성 (Claude Haiku로 풀어쓰기)
  4. 월 1회 알림 메일·대시보드 배너로 안내

좋은 폴더 이름 짓기

AI는 단순히 분류만 하는 게 아니라 폴더 이름도 짓습니다. 좋은 이름의 조건:

  • 짧고 구체적 — "자유의지" (좋음) vs "철학적 사유" (모호함)
  • 연라이프 정서 — "학생 질문" 보다 "교실의 순간들" 같은 결
  • 본인이 이미 쓴 표현 — 스크랩 안에 자주 나오는 단어
  • 거부할 수 있음 — "이 이름 별로예요" → 본인이 다시 짓기

05데이터 구조

D1 테이블 추가. 기존 scraps 테이블에 folder_id 필드 추가 + 새 folders 테이블.

// 폴더 테이블 CREATE TABLE folders ( id TEXT PRIMARY KEY, user_id TEXT NOT NULL, parent_id TEXT, -- NULL이면 최상위 폴더 name TEXT NOT NULL, emoji TEXT, -- 📁, 📂, 📦, 📚 등 color TEXT, -- 팔레트 안 색 order_idx INTEGER, -- 표시 순서 representative_vector BLOB, -- 폴더 임베딩 (자동 갱신) created_at DATETIME DEFAULT CURRENT_TIMESTAMP, created_by TEXT -- 'user' or 'ai' ); // scraps에 폴더 연결 (다대다 — 한 별이 여러 폴더에) CREATE TABLE scrap_folders ( scrap_id TEXT NOT NULL, folder_id TEXT NOT NULL, is_primary BOOLEAN DEFAULT 1, -- 주 폴더 (지도 색 결정용) added_at DATETIME DEFAULT CURRENT_TIMESTAMP, added_by TEXT, -- 'user' or 'ai_auto' or 'ai_suggested' PRIMARY KEY (scrap_id, folder_id) ); // 인덱스 CREATE INDEX idx_folders_user ON folders(user_id, parent_id); CREATE INDEX idx_sf_scrap ON scrap_folders(scrap_id); CREATE INDEX idx_sf_folder ON scrap_folders(folder_id);
왜 다대다(N:M) 관계인가 한 별이 동시에 여러 폴더에 있을 수 있어야 자연스러워요. "동서양 비교" 별이 "철학" 폴더에도 있고 "교실의 순간들" 폴더에도 있을 수 있죠. 단, "주 폴더" 하나는 정해서 지도에서 별 색깔의 기준으로 씁니다.

06UI 디테일 — 새벽의 신뢰 결로

폴더 아이콘 — 단정한 한 톤

이모지를 쓰되 자극적이지 않게. 폴더 이모지는 다섯 가지로 제한.

  • 📁 일반 폴더 (기본)
  • 📂 정리되지 않음 (임시)
  • 📚 책처럼 묶인 모음 (자서전 후보)
  • 🔖 즐겨찾기·핵심 폴더
  • 🗂 사용자 직접 만든 폴더

폴더 색 — 새벽의 신뢰 팔레트 안

5가지만:

  • 딥 틸 (#2A5358) — 사유·철학
  • 잿빛 푸름 (#4A6878) — 사회·관계
  • 호박 (#A87B3E) — 강조·즐겨찾기
  • 먹빛 (#1A2326) — 기본·정돈
  • 연한 회색 (#8A9398) — 임시·정리되지 않음

드래그·드롭 — 단순하게

  • 별을 드래그해서 다른 폴더로 이동
  • 별을 드래그해서 새 폴더 만들기 (다른 별 위로 떨어뜨림)
  • 폴더 자체를 드래그해서 순서 변경
  • 폴더 더블 클릭으로 이름 변경

검색 — 폴더 무시하고 전체

검색은 항상 전체 별을 대상으로. 결과에 폴더 정보가 함께 표시됨 (어디서 찾았는지).

09약속 — 폴더가 갇히지 않도록

  • 모든 AI 제안은 거부 가능 — "이번엔 그대로 두기" 버튼 항상
  • 한 별을 여러 폴더에 — 강제 분류 X
  • "전체 보기"가 기본 — 폴더는 옵션, 보고 싶을 때만
  • 폴더 무시 검색 — 검색은 항상 전체 대상
  • 되돌리기 — 30일 이내 어떤 변경도 되돌릴 수 있음
  • 본인 폴더 구조 항상 공개 — 어떤 AI가 무슨 기준으로 분류했는지 설명 가능
"폴더 너무 많아져요" 처방 AI가 폴더를 너무 자주 만들면 답답해질 수 있어요. 그래서: (1) 한 폴더에 별이 3개 이상 모이기 전엔 새 폴더 만들지 않음, (2) 한 사용자당 최대 30개 폴더(2단계 깊이까지), (3) 6개월 안 쓴 폴더는 자동 보관함으로 이동 제안.
정리

"별이 모이고, 별이 정돈되고, 별이 다시 흩어집니다"

스크랩 시스템 = 별을 모으는 일

스마트 폴더 = 별을 정돈하는 일 (AI가 도움)

별자리 지도 = 별이 다시 흩어져 별자리가 되는 일

세 가지가 함께 있을 때 — 주민의 사유가 모이고, 정돈되고, 다시 자유롭게 펼쳐지는 자기 우주가 만들어집니다.

회원 1년 사용 후 — 평균 500개 별 · 15개 폴더 · 자기만의 우주 한 권. 이게 자서전 공방(2027)으로 이어집니다.
