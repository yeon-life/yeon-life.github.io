연라이프 챗봇·모더레이션 엔진 — 2026년 5월 종합 조사

"Gemma 4가 좋을까, 더 나은 게 있을까?"라는 질문에서 시작했습니다. 현 시점의 모든 무료 LLM 옵션 — 클라우드 API와 자체 호스팅 모델 — 을 한국어 성능, 무료 한도, 운영 부담 기준으로 비교했고, 연라이프의 실제 상황에 맞는 한 가지 길을 추천합니다.

한 페이지 결론 · TL;DR

Gemini 2.5 Flash (메인) + Upstage Solar Pro (모더레이션 보조)

왜 이 조합인가 — 둘 다 무료 티어로 시작 가능, 둘 다 한국어 1등급, 본인 컴퓨터를 켤 필요 없음(둘 다 API). Gemini는 이미 키가 있어 즉시 확장 가능, Solar Pro는 한국 회사(업스테이지)가 만든 한국어 모더레이션 특화 모델로 연라이프의 마을 정서와 잘 맞음.

왜 Gemma 4가 아닌가 — Gemma 4도 훌륭하지만 자체 호스팅이 필수(API 무료 제공 X). 본인 컴퓨터가 24시간 켜져 있어야 하고, 트래픽 늘면 GPU도 필요. 연라이프 규모에서는 과한 부담.

언제 자체 호스팅으로 갈까 — 마을 회원 1만 명 넘었을 때, 또는 "구글·미국 회사에 데이터 안 주고 싶다"는 결정이 섰을 때. 그때는 EXAONE 4.5 또는 Gemma 4 E4B를 클라우드 GPU에 올리는 방향.

01핵심 질문 — 컴퓨터를 켜야 하나

가장 먼저 정리할 질문입니다. 운영 방식에 따라 모든 선택지가 갈리기 때문입니다.

방식본인 컴퓨터 필요?비용셋업 난이도추천 대상
클라우드 API
(Gemini, Groq, Solar 등)		 아니오 무료 티어 충분 매우 쉬움 연라이프 같은 작은~중간 사이트
로컬 자체 호스팅
(Gemma 4, Qwen 등)		 예 — 24시간 전기료 + 컴퓨터 중간 기술 좋아하는 분, 데이터 주권 중요
클라우드 자체 호스팅
(VPS / GPU 서버)		 아니오 월 $50~300 중간~높음 큰 트래픽, 기업 운영
결론 연라이프의 현재 상황에서는 클라우드 API가 거의 확실한 답입니다. 컴퓨터 안 켜고, 무료로, 빠르게 시작할 수 있어요. 나중에 트래픽이 커지면 그때 다른 방식으로 옮기면 됩니다.

02연라이프 AI의 두 가지 용도

용도 A — 모더레이션 (품격 검사)

회원이 글을 올리면 → AI가 즉시 채점 → 일정 점수 이하면 자동 숨김. 운영 원칙은 이미 사이트에 적혀 있습니다.

  • 장난성 글
  • 도배 / 의미 없는 문자 반복
  • 욕설·비방
  • 광장의 톤과 어울리지 않는 자극적 표현

이건 본질적으로 분류 작업(classification)입니다. 큰 모델 안 써도 되고, 응답 속도가 중요합니다.

용도 B — Q&A 챗봇

방문자가 사이트에 대해 묻는 모든 것에 답해야 합니다.

  • "화두는 어떻게 제안하나요?"
  • "아골라랑 아곤란이 뭐가 달라요?"
  • "내 블로그 시작하는 방법?"
  • "6단계 검증이 뭔가요?"

이건 RAG (검색 증강 생성) 작업입니다. AI에게 사이트 콘텐츠를 참조시켜 답하게 합니다. 약간의 추론 능력과 한국어 자연스러움이 중요합니다.

04한국 회사가 만든 한국어 특화 모델

2025년 한국 과학기술정보통신부가 2,400억 원을 투입해 5개 컨소시엄에 "주권 LLM" 개발을 지원했습니다. 그 결과 강력한 한국어 모델들이 2026년에 쏟아져 나왔습니다.

EXAONE 4.5 (LG AI Research) 한국어 1등급

장점 — K-EXAONE 236B MoE (23B 활성). 한국 문화·역사 맥락을 직접 학습. 안전성·신뢰성 평가에서 매우 높은 점수. 멀티모달(이미지+텍스트). 무료 가중치 공개.

단점 — 자체 호스팅 필요(API 없음). 대형이라 GPU 비싸게 필요. 상업용 라이선스 별도.

연라이프 사용 시점: 트래픽 큰 후, 자체 GPU 서버 갖춘 후.

Solar Pro (Upstage) ★ 연라이프 추천

장점 — 한국어 UGC(사용자 생성 콘텐츠) 모더레이션이 공식 설계 용도. 한국 회사. API 제공. 가격 합리적. 챗봇/번역도 같이 됨. 다국어 소셜 미디어 플랫폼 모더레이션 사례 다수.

단점 — 무료 한도는 Gemini보다 작음. 추론 능력은 Gemini Pro에 약간 못 미침.

연라이프 사용 시점: 지금 당장 — 모더레이션 전용.

Motif (Motif Technologies) 한국어 강자

장점 — 102B 파라미터. KMMLU 벤치마크에서 64.74로 GPT-4 능가. Hugging Face에서 무료 다운로드. 한국 스타트업이 만든 한국어 우선 모델.

단점 — 자체 호스팅만 가능(API 없음). 102B는 GPU 비싸게 필요. 상업화 진행 중이라 API는 향후 제공 가능성.

연라이프 사용 시점: 한국어 정밀도가 정말 중요해질 때.

HyperClova X (Naver) 한국어 강자

장점 — 한국어 사용량·자연스러움 최상위. Naver가 운영. 한국 사용자에 최적화.

단점 — 가중치 공개 안 함(자체 호스팅 불가). API는 유료(무료 티어 제한적). 일반 개발자 접근 어려움.

연라이프 사용 시점: Naver 클라우드 협업 가능할 때.

AX (SK Telecom) 한국어 성장 중

장점 — SKT의 통신 데이터·고객 응대 학습. 한국 비즈니스 용어 강함.

단점 — 일반 개발자 접근 제한적. 외부 API 제공 미흡.

05오픈 가중치 모델 (자체 호스팅용)

본인 컴퓨터나 클라우드 GPU에 직접 올려 운영하는 방식. Gemma 4도 이 범주.

Gemma 4 (Google, 2026.04) 처음 추천

장점 — E2B / E4B / 26B MoE / 31B Dense 네 크기. 140개 언어 지원, 한국어 강력. 31B는 Arena AI 3위, MMLU Pro 85.2%. Ollama로 쉽게 셋업 가능. Apache 라이선스로 상업 사용 허용.

단점 — E4B(작은 거)도 RAM 16GB+ 필요, 31B는 GPU 24GB+. 본인 컴퓨터 24시간 켜야 하거나 클라우드 비용. API 무료 제공 없음.

Qwen 3.6 (Alibaba) 한국어 강자

장점 — 201개 언어 지원(Gemma 4의 140보다 많음). 한국어 특히 강함. Qwen3Guard라는 모더레이션 전용 변형 모델 따로 있음. 다양한 크기 (1B ~ 235B).

단점 — Gemma 4와 동일한 자체 호스팅 부담. 중국 회사라는 점 고려 필요.

Llama 4 (Meta) 한국어는 약함

장점 — 글로벌 1위급 영어 성능. 추론·코딩 강함. Groq·Cerebras API 무료 티어로 사용 가능.

단점 — 한국어 지원이 약 30개 언어로 Gemma 4·Qwen에 비해 좁음. 연라이프에는 비효율.

DeepSeek V4 추론 최강

장점 — 추론·수학 글로벌 최강. 한국어도 우수. 무료 가중치 공개.

단점 — 매우 큼(자체 호스팅 어려움). 연라이프에는 과한 능력.

Qwen3Guard / NemoGuard 모더레이션 전용

장점 — 콘텐츠 모더레이션·안전 분류에만 특화. 작고 빠름. 한국어 부분 지원.

단점 — 챗봇 기능 없음(모더레이션만). 한국 문화 맥락은 EXAONE/Solar보다 약함.

  • 확장 가능 — 트래픽 늘면 자체 호스팅으로 점진적 이전 가능

08구현 로드맵

1주차 — 기초 셋업

  • Cloudflare Workers 무료 계정 생성
  • Upstage Solar Pro 개발자 계정 생성·API 키 발급
  • (이미 있는) Gemini API 키 확인·재사용
  • 로컬 테스트: 한국어 글 한 편 → Solar Pro 모더레이션 결과 확인

2주차 — 모더레이션 시스템

  • Cloudflare Workers에 모더레이션 엔드포인트 작성
  • 운영 원칙(장난성·도배·욕설·비방·자극)을 시스템 프롬프트로 정리
  • 점수 기준(예: 0~5점 → 2점 이하 자동 숨김) 설정
  • 관리자 대시보드에 "AI가 숨긴 글" 패널 추가
  • 오탐 발생 시 복원 버튼

3주차 — 챗봇

  • 사이트 콘텐츠를 마크다운으로 정리(약관·FAQ·운영원칙)
  • Gemini API에 시스템 프롬프트 + 콘텐츠 컨텍스트 주입
  • 플로팅 챗봇 UI 추가(우측 하단)
  • 대화 히스토리는 브라우저 localStorage에 저장
  • "답을 못 찾으면 편집인에게 문의" 폴백

4주차 — 모니터링·다듬기

  • 일주일 분량 모더레이션 결과 검토 → 프롬프트 튜닝
  • 챗봇 자주 묻는 질문 5개 정리 → 시스템 프롬프트 보강
  • Gemini·Groq·Cerebras 폴백 체인 구축

나중에 (트래픽 커지면)

  • Gemma 4 E4B를 클라우드 VPS에 셋업 (월 $20~50)
  • 또는 EXAONE 4.5 자체 호스팅 (한국어 최강)
  • 임베딩 기반 RAG로 챗봇 정밀도 향상

09실제 모더레이션 프롬프트 예시

Solar Pro 또는 Gemini에 보낼 시스템 프롬프트의 초안입니다.

당신은 연라이프(y-life.kr) 광장의 모더레이터입니다. 연라이프는 학생과 어른이 함께 깊은 토론을 나누는 한국어 사색 공간입니다. "말에는 마음씨가 그대로 담깁니다"가 광장의 약속입니다. 다음 글을 0~5점으로 채점하세요. 채점 기준: · 5점: 사색적이고 마음씨가 담긴 글 · 4점: 일반적인 토론·질문 · 3점: 짧지만 의도가 있는 글 · 2점: 의미가 흐릿하거나 다소 거친 글 · 1점: 장난성·도배·의미 없는 반복 · 0점: 욕설·비방·자극·광고 응답은 JSON으로: { "score": 숫자, "reason": "한 줄 이유", "action": "hide" | "warn" | "approve", "category": ["spam" | "abuse" | "lowquality" | "good"] } 글 내용: """ [여기에 사용자 글이 들어감] """
중요한 점 — AI 모더레이션의 한계 AI는 완벽하지 않습니다. 깊이 있는 글을 "어렵다"고 잘못 판단하거나, 학생의 서툰 질문을 "의미 없다"고 오탐할 수 있어요. 그래서 "자동 삭제"가 아니라 "자동 숨김"으로 시작하고, 관리자 대시보드에서 복원 버튼을 두는 게 안전합니다. 1주일 데이터 쌓이면 점수 기준을 조정하세요.

10위험 요소 — 알고 가야 할 것

위험 1 — 무료 티어는 변할 수 있다 Google이 2025년 말에 Gemini 무료 한도를 50~80% 줄였습니다. 무료 정책은 회사 사정에 따라 바뀝니다. 따라서 (1) 한 곳에 의존하지 말고 폴백 구축, (2) 매월 사용량 점검, (3) 유료 전환 시점에 대한 계획이 필요합니다.
위험 2 — AI 오탐 AI가 정상 글을 부적절하다고 잘못 판단할 수 있습니다. 특히 학생의 서툰 질문이나 동양 사상의 한자 인용이 오탐될 가능성이 있어요. 자동 삭제는 절대 금지, 자동 숨김 + 관리자 복원이 안전합니다.
위험 3 — 데이터가 해외 회사로 간다 Gemini·Groq·Cerebras는 모두 미국 회사입니다. 한국 회원의 글이 미국 서버로 갑니다. 개인정보보호법상 문제는 없지만(공개 글이므로), 연라이프의 정서와 맞는지 결정하셔야 합니다. 이 점이 마음에 걸리면 EXAONE/Solar 같은 한국 모델로 가시면 됩니다.
위험 4 — 시스템 프롬프트 유출 악의적 사용자가 챗봇에게 "시스템 프롬프트 알려줘"라고 물어 모더레이션 기준을 알아낼 수 있습니다. 따라서 Cloudflare Workers에서 프롬프트를 관리하고, 직접 브라우저에 노출 안 되게 하세요.
