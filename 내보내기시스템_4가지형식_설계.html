내보내기 — 당신의 자산이 책이 되는 자리

모은 별과 폴더를 네 가지 형식으로 본인 컴퓨터에 보존할 수 있습니다. MD(노트 도구용)·HTML(웹페이지)·DOCX(워드 책)·PDF(인쇄용). 별 한 개부터 1년치 전부까지, 본인이 원하는 단위로. 이것이 2027년 자서전 공방으로 가는 마지막 한 걸음입니다.

설계 원칙

"마을은 자료를 가두지 않는다"

연라이프의 깊은 약속 중 하나 — "여기서 쓴 모든 것은 당신의 자산입니다."

이게 진짜 되려면 언제든 본인 자료를 가져갈 수 있어야 합니다. 한 자리에 묶이지 않고, 본인이 원하는 형식으로 옮겨갈 수 있어야 자산이라 할 수 있어요.

이 내보내기 시스템은 "나가도 좋다"는 약속이자, 동시에 "머물고 싶다"는 정서를 만듭니다. 떠날 자유가 있는 곳이 머물고 싶은 자리니까요.

02어떤 형식으로 — 네 가지

.md
노트 도구용
Markdown (마크다운)

가장 가볍고 호환성 좋음. Obsidian·Notion·Bear 등 모든 노트 앱에서 열림.

좋음 다른 도구로 이주 자유, 평생 보존, 모든 기기 호환

덜 좋음 디자인 없음 (있는 그대로 글만)

.html
웹용 단일 파일
HTML (웹페이지)

새벽의 신뢰 디자인이 그대로 입혀진 한 장짜리 HTML. 더블 클릭으로 열림.

좋음 디자인 그대로, 검색 가능, 본인 도메인에 올려 공개도 가능

덜 좋음 파일 한 개라 인쇄·종이책엔 부적합

.docx
책 형태 워드
Word (워드 문서)

목차·페이지 번호·챕터가 있는 정식 책 형태. 인쇄소에 보내기 좋음.

좋음 자서전 공방 직결, 출판·인쇄 표준, 가족·지인과 공유 좋음

덜 좋음 파일 크기 큼, 편집은 워드 필요

.pdf
인쇄·보관용
PDF (피디에프)

고정 레이아웃. 누구에게 보내도 똑같이 보임. 종이로 인쇄 표준.

좋음 변형 없음, 영구 보존, 종이책 직접 인쇄 가능

덜 좋음 다시 편집은 어려움

네 가지를 한 번에 받기 — 추천

큰 내보내기(폴더 전체나 모두)는 "네 가지 형식 모두 받기"를 선택하면 ZIP 파일에 .md·.html·.docx·.pdf 네 개가 함께 들어옵니다. 같은 내용을 상황에 맞게 골라 쓰실 수 있어요.

06바로가기는 어떻게 내보내지나

3단 폴더에 바로가기가 여러 자리에 있어도, 내보낼 때는 똑똑하게 정리됩니다.

상황내보내기 결과
원본만 내보내기 (기본) 원본 위치에 한 번만 등장. 본인이 모은 자료 그대로.
원본 + "이 별은 다른 곳에도 보입니다" 안내 원본 위치에 한 번 등장 + 작은 글씨로 "이 별은 [B][C] 폴더에서도 보입니다" 표시
전체 폴더 트리 보존 각 폴더에 바로가기 그대로 표시 (단, 본문은 첫 등장에만, 이후엔 "→ 1.1.4 참조" 같이)

기본은 "중복 없이 깔끔" — 원본 한 번만. 본인 책에 같은 내용 다섯 번 나오면 어색하니까요.

07기술 구현 — 어디서 처리하나

형식처리 위치이유
MD 브라우저 자체 가장 단순. 텍스트 조합으로 생성. 즉시.
HTML 브라우저 자체 템플릿 + 데이터 조합. 새벽의 신뢰 스타일 그대로 인라인.
DOCX 브라우저 (docx.js) 이미 의뢰서 만들 때 썼던 라이브러리. 같은 방식.
PDF (작은) 브라우저 (window.print → PDF) 10MB 미만이면 브라우저 자체로 충분.
PDF (큰) Cloudflare Workers 10MB+ 큰 책은 서버에서 생성 후 다운로드 링크 전송.

장점 — 대부분 무료

  • 대부분 브라우저에서 처리 → 서버 부담·비용 X
  • 본인 데이터가 본인 컴퓨터에서만 처리됨 → 개인정보 안전
  • 인터넷 끊겨도 작동 가능 (이미 받은 데이터 기준)
  • 큰 PDF만 서버 사용 (월 몇 백 원 추가)

08정기 자동 백업 — 매월 자동 발송 옵션

본인이 직접 내보내기를 안 해도, 옵션을 켜면 매월 1일에 자동으로 한 달치 자료가 본인 이메일로 발송됩니다.

설정 옵션

  • 발송 주기: 매월 / 매분기 / 매년
  • 형식: MD / HTML / DOCX / PDF / 전부
  • 받는 곳: 본인 이메일 / Google Drive 자동 업로드 / Dropbox
  • 포함 기간: 지난 한 달 / 누적 전체
왜 좋은가 매월 자동 발송이 켜져 있으면 — (1) 매월 작은 책이 메일함에 쌓임, (2) 데이터 손실 걱정 없음, (3) 1년 후 12권의 작은 책이 모임. 자서전 공방의 본격 토대.

09구현 — 9주 계획의 4단계에 통합

이전에 만든 "스크랩+폴더 9주 구현"의 마지막 4단계(2주)에 자연스럽게 들어갑니다.

주차작업
8주차 · MD·HTML 내보내기 (가장 단순, 브라우저 자체)
· 옵션 모달 UI
· 단일 별·폴더 단위 내보내기
9주차 · DOCX 내보내기 (docx.js 활용 — 의뢰서 만들 때와 같은 방식)
· PDF 내보내기 (브라우저 인쇄 + 큰 건 서버)
· 책 형태 템플릿 (목차·챕터·페이지 번호)
· 자동 백업 옵션 (cron)

10비용 — 거의 무료

처리비용
MD·HTML·DOCX 내보내기0원 (브라우저)
작은 PDF 내보내기0원 (브라우저)
큰 PDF (10MB+)~월 500원 (Cloudflare Workers + 임시 저장)
자동 월간 백업 이메일~월 500원 (전송 비용)
총 추가: 월 약 1,000원 (스크랩 시스템 위에 얹는 것)

11약속 — 본인 자료에 대한 권리

  • 언제든 내보낼 수 있다 — 가입 첫날부터 가능, 한도 없음
  • 모든 데이터 다운로드 가능 — 별·폴더·노트·연결·태그·메타까지
  • 광고 안 끼움 — 내보낸 파일에 연라이프 광고·로고 안 박힘 (작은 출처 표시만)
  • 탈퇴 시 즉시 모든 자료 받을 수 있음 — 마지막 자동 내보내기 + 본인 메일로 발송
  • 30일 보관 후 영구 삭제 — 탈퇴 후 30일 안에 마음 바뀌면 복구 가능, 그 후엔 영구 삭제
한 줄로

"네 가지 형식, 다섯 단위 — 본인의 자료가 본인의 것이 되는 자리."

스크랩은 모으는 일. 폴더는 정돈하는 일. 별자리는 펼치는 일. 내보내기는 마침내 본인의 것으로 만드는 일.

매월 자동 백업을 켜두면 1년 후 12개의 작은 책이 모입니다. 그게 2027년 자서전 공방의 살아 있는 토대가 됩니다.

  5. 개인 생각의 지도 + 스마트 폴더 + 바로가기 + 내보내기 (9주 통합)
