발견된 문제

문제 1 — GitHub 리포 파일 자체가 불완전한 버전

GitHub 리포의 yeong-pul.html은 Netlify 원본과 다른 파일이었다. applyTheme, resetSettings, printShareCard, openSettingsModal 등 핵심 함수들이 누락되어 있었고, 이 때문에 버튼을 눌러도 아무 반응이 없었다.

문제 2 — JS 코드가 텍스트로 렌더링됨

일부 파일에서 </script> 태그가 JS 문자열 내부에 unescaped 상태로 포함되어 있어, 브라우저가 스크립트 블록을 중간에 닫아버렸다. 이후 코드가 일반 텍스트로 페이지 하단에 노출되었다.

문제 3 — 그림판 버튼 UI 누락

그림판 함수(openDrawingPadModal 등)는 정의되어 있었지만 UI에 버튼이 없어서 사용자가 그림판을 호출할 방법이 없었다.

해결 방법

해결 1 — deploy/app.html 원본으로 완전 교체

불완전한 GitHub 리포 파일을 버리고, Netlify 원본인 C:\Users\jinwo\yeon-teacher\deploy\app.html을 기반으로 새로 작업. 모든 핵심 함수가 온전히 보존된 상태에서 기능 추가만 수행.

해결 2 — v3 동결, v4 작업본 분리

기존 작업 폴더를 yeon-ai-kr-v3로 동결(건드리지 않음)하고, yeon-ai-kr-v4를 새로운 작업본으로 생성. v4에서만 수정 진행.
