발송 정책 (YLV-4 §12)

  • 발송 시각: 매일 06:30 KST (자동 발행 직후)
  • 대상: 카카오 채널 친구 + 알림톡 동의 회원만
  • 주말·공휴일: 동일 발송 (옵션 — 회원이 설정 가능)
  • 휴재일(부재 모드): 발송 생략 + 안내 1통
  • 발송 실패 시: 1시간 후 재시도, 3회 실패 시 큐 폐기
  • 수신 거부: 카카오 채널 차단으로 즉시 적용

알림톡 vs 친구톡 vs 채널톡

유형대상비용승인
알림톡전화번호 보유 회원건당 약 8원템플릿 사전 승인 필요
친구톡카카오 채널 친구건당 약 8~15원광고성 가능
채널 메시지채널 친구무료~약 15원일 발송 한도 있음
주의: 카카오 알림톡 템플릿은 카카오비즈니스에서 사전 심사를 받아야 합니다. 광고성 표현·이모지 사용에 제약이 있으므로 본 템플릿은 채널톡(친구톡)으로 발송하거나, 알림톡 심사 통과 후 사용하세요.

이메일 백업 (구독자용)

알림톡 동의 안 한 회원에게는 같은 내용을 Resend 로 이메일 발송. HTML 템플릿은 별도 파일.

발송 시스템

  1. Cloudflare Workers Cron 매일 06:30 KST 트리거
  2. articles_published 에서 오늘 발행 글 13편 조회
  3. 신뢰도 ≥ 80 + 카테고리 균형으로 3편 선정
  4. 화두 본문 + 3편 제목·페르소나·신뢰도 슬롯 치환
  5. 카카오 비즈 API + Resend 이메일 동시 발송
  6. 발송 결과 y_usage_events 에 기록
