1 광장글 상세페이지 라우팅 예외 처리 배포완료

파일: 단계2_광장글_상세페이지.html · 커밋 f54ca4b

문제

  • URL의 title/id가 ARTICLES에 없으면 조용히 기본 Libet 글로 튕김 (주소≠화면, 혼란)
  • 빵부스러기 "아골라" 링크(?forum=아골라&title=…전체 보기)도 Libet로 튕김
  • 부분일치 titleParam.includes(k.slice(0,12)) 가 엉뚱한 글로 오매칭 위험

수정

  • 못 찾으면 "찾는 글을 만나지 못했습니다" 안내 화면 + 지금 읽을 수 있는 글 목록 렌더 (Libel 글로 안 튕김)
  • 게시판 링크는 "○○ 글 모음" 포럼 목록 화면(해당 포럼 글만 필터)
  • 부분일치를 6자 이상·양방향 포함만 허용하는 안전 매칭으로 교체(resolveArticleKey)
  • 파라미터 없음=기본 Libet 글, 정상 글=동적 렌더 — 기존 동작 보존

검증

  • 4시나리오 브라우저 확인: 글없음 / 포럼목록 / 정상글 / 기본화면 모두 정상
  • verify_deployment.py Quality Gate Passed
  • y-life.kr 라이브 소스에 resolveArticleKey 반영 확인

2 임선생 글쓴이 사진 표시 수정 배포완료

파일: index.html, 단계2_광장글_상세페이지.html · 커밋 416bbf3

진짜 원인

사진(assets/avatars/lim-teacher.png, 임선생 초상)은 있었으나, 글자 林에 z-index:1이 붙어 사진을 덮고 있었음 → 로드돼도 글자 뒤에 숨음.

수정

  • 글자를 사진 뒤로(z-index 제거), 사진이 위에 표시 / 로드 실패 시에만 글자 폴백(onerror)
  • 적용: 홈 index.html "이번 주 칼럼" 임선생 카드 + 단계2 글쓴이 영역·사이드바

검증

  • 로컬·라이브에서 임선생 사진 정상 표시(스크린샷 확인)
  • 라이브에 버그패턴(z-index:1;">林) 잔존 0건
참고: 연소사(蓮)·박주민(朴)·현지영(玄)은 사진 파일이 없어 글자 유지 — 아래 자동화로 채울 예정.

위치: assets/avatars/_automation/ (사이트 미배포 — .gitignore 처리). 사진(PNG)만 assets/avatars/에 저장되어 배포.

"전혀 묻지 않는" 자동화 장치

  • 연소사 본인 사진 = 질문 대신 기본값 蓮 글자 유지(skip, 가공 얼굴 임의 생성 안 함)
  • 페르소나 12명 성별 = 이름·나이·분야로 Claude 추정 확정(genderAssumed)
  • Claude 픽업·배포도 무질문 자율 처리
